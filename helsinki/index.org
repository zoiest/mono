* Overview of Helsinki Studies

This repository houses the unified mathematical knowledge base for courses across the *Department of Mathematics and Statistics* and the *Department of Physics* at the *University of Helsinki (Helsingin yliopisto)*. 

All course directories contain exhaustive lecture notes, formal proofs, step-by-step problem sets, and strategic prerequisite bridging materials formatted in Emacs Org-mode and compiled into HTML via Bazel.

* Conceptual Cross-Discipline Synergies

#+caption: Cross-Course Analytical Connections
| Foundational Engine | How It Manifests in Each Course |
|---------------------+---------------------------------|
| *Lebesgue Measure & Integration* | - *Real Analysis:* Abstract measure spaces $(X, \mathcal{F}, \mu)$ and $L^p$ spaces.<br>- *Fourier Analysis:* Justifying differentiation under the integral (DCT) and convolutions (Fubini-Tonelli).<br>- *Financial Economics:* Probability spaces $(\Omega, \mathcal{F}, \mathbb{P})$, expectation of payoffs, and equivalent martingale measures $\mathbb{Q} \sim \mathbb{P}$. |
| *\(L^2\) Hilbert Spaces & Orthogonality* | - *Fourier Analysis:* Plancherel theorem, Parseval identity, orthogonal projection onto Fourier basis $\{e^{inx}\}$.<br>- *Quantum Mechanics:* State spaces $\mathcal{H}$, symmetry operators $U_g$, and representation theory.<br>- *Financial Economics:* Mean-Square Error Hedging as orthogonal projection $\operatorname{proj}_{\operatorname{Im}(S(1))}(X)$. |
| *Monotone Classes & Dynkin's \(\pi\)-\(\lambda\)* | - *Probability & Real Analysis:* Proving uniqueness of probability distributions from CDFs.<br>- *Financial Economics:* Generating market filtrations $(\mathcal{F}_t)$ and proving uniqueness of martingale measures. |

* Build Tools and Operations

All courses utilize Bazel rules defined at the monorepo root:

1. *Compile All Helsinki Org Files to HTML:*
   #+begin_src bash
   bazel run //helsinki:org2html
   #+end_src
   Or compile a single course:
   #+begin_src bash
   bazel run //helsinki/measure_integral:org2html
   bazel run //helsinki/intro_fourier:org2html
   bazel run //helsinki/measure_probability_analysis:org2html
   bazel run //helsinki/financial_economics_1:org2html
   bazel run //helsinki/maths_physics_3a:org2html
   #+end_src

2. *Google Drive Synchronization:*
   #+begin_src bash
   bazel run //helsinki:sync
   #+end_src
   To preview files without transferring:
   #+begin_src bash
   bazel run //helsinki:sync -- --dry-run
   #+end_src
