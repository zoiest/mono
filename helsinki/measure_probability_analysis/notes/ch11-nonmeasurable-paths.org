* Overview

** What problem does this chapter solve?

Why did we spend so much effort carrying a \(\sigma\)-algebra \(\mathcal F\) around inside every
probability space \((\Omega, \mathcal F, \mathbb P)\), instead of simply assigning a probability to
*every* subset of \(\Omega\)? A beginner might hope that \(\sigma\)-algebras are just a technical
scaffolding and that, especially after completing the measure (Proposition 5.14), every reasonable
set is measurable anyway.

This chapter shows why that hope fails, in two completely different ways:

1. *Symmetry + Axiom of Choice destroys universal measurability (Section 11.1).* Even on the
   concrete fair-coin space \(\Omega = \{0,1\}^{\mathbb N}\), flipping finitely many coins leaves
   probabilities unchanged. Using the Axiom of Choice to pick one sequence per equivalence class
   produces a set \(V\) that cannot be assigned a probability — not even in the *completion* of the
   fair-coin space (Proposition 11.1). This is the coin-toss cousin of Vitali's nonmeasurable set on
   the circle.
2. *Countable operations can only see countably many coordinates (Section 11.2).* When we move from
   discrete time \(\mathbb N\) to continuous time \(I = [0,1]\), the product \(\sigma\)-algebra on
   \(\mathbb R^{[0,1]}\) is generated by cylinder sets. Because \(\sigma\)-algebras only allow
   *countable* unions and intersections, every set in the product \(\sigma\)-algebra depends on at
   most countably many time coordinates (Proposition 11.2). As a shocking consequence, geometrically
   natural sets of functions — such as the single identically zero path (Example 11.3) or the set
   \(C([0,1])\) of all continuous paths (Example 11.4) — are *not* in the product \(\sigma\)-algebra!

** Probability motivation

In continuous-time probability (such as Brownian motion, stock price models, or random fields
indexed by \(t \in [0,1]\)), we want to ask pathwise questions:
- "Is the sample path \(t \mapsto X_t(\omega)\) continuous?"
- "What is the probability that \(\sup_{0 \le t \le 1} X_t > a\)?"

If we model paths inside the giant product space \(\mathbb R^{[0,1]}\), these questions involve
uncountably many coordinates \(t \in [0,1]\) at once, and Examples 11.3–11.5 show that things go
badly wrong: two processes can satisfy \(\mathbb P(X_t = Y_t) = 1\) at *every single time \(t\)* and
have identical finite-dimensional distributions, yet one has purely continuous paths while the other
has a discontinuity on *every* path (Example 11.5, the "random spike").

Section 11.4 shows how probability theory resolves this: once we know a process has continuous paths,
we change the sample space itself to \(C([0,1])\) equipped with the uniform norm
\(\|f\|_\infty = \sup_{0\le t\le 1} |f(t)|\). Because a continuous function is completely determined
by its values at *rational* times \(q \in \mathbb Q \cap [0,1]\), the Borel \(\sigma\)-algebra on
\(C([0,1])\) is generated by countably many coordinate evaluations (Proposition 11.6), and pathwise
quantities like \(\sup_{t \in [0,1]} f(t)\) become honestly measurable (Example 11.7).

* 11.1 Changing finitely many bits

** Intuition

Imagine tossing a fair coin infinitely many times: \(\omega = (\omega_1, \omega_2, \dots) \in \{0,1\}^{\mathbb N}\).
Suppose a mischievous demon comes along and flips a known, deterministic finite set of coins — say,
the 1st, 3rd, and 7th tosses — turning \(0 \leftrightarrow 1\) in those slots while leaving all other
tosses alone. Since each individual coin is fair (\(0\) and \(1\) each have probability \(1/2\)),
flipping the 1st, 3rd, and 7th outcomes does not change the probability of any cylinder event! In
fact, this bit-flip map \(T_F\) preserves the fair-coin measure \(\mathbb P\) completely.

Now group sequences into equivalence classes by saying \(\omega \sim \eta\) if they agree from some
point onwards (they differ in only finitely many coordinates). Each equivalence class is a countable
family of sequences, all obtained from one another by finite bit flips \(T_F\). If we use the Axiom
of Choice to pick *one* "representative" sequence from each equivalence class and call the set of
chosen representatives \(V\), then the whole space \(\Omega = \{0,1\}^{\mathbb N}\) is partitioned
into countably many disjoint copies \(T_F(V)\) (one for each finite subset \(F \subseteq \mathbb N\)),
all of which must have the *exact same* probability \(\mathbb P(V)\):

#+begin_example
   Omega = {0,1}^N  (total probability = 1)
   +-------------+-------------+-------------+-------------+---
   |   T_empty V |   T_{1} V   |   T_{2} V   |  T_{1,2} V  |  ...  (countably many
   |    = V      |             |             |             |        disjoint copies)
   |  prob = a   |  prob = a   |  prob = a   |  prob = a   |
   +-------------+-------------+-------------+-------------+---
#+end_example

What can the common probability \(a = \mathbb P(V)\) be?
- If \(a = 0\), the countable sum \(a + a + a + \dots\) is \(0\), not \(1\).
- If \(a > 0\), the countable sum \(a + a + a + \dots\) is \(\infty\), not \(1\).

Either way, countable additivity breaks! Thus \(V\) cannot be measurable — not even after we throw in
all subsets of null sets (completion).

** The equivalence relation and the choice set

On the fair-coin space \(\Omega = \{0,1\}^{\mathbb N}\), we define a relation \(\omega \sim \eta\) by declaring
that \(\omega \sim \eta\) if and only if they differ in only finitely many coordinates:
\[
\omega \sim \eta \quad \Longleftrightarrow \quad \{n \in \mathbb N : \omega_n \ne \eta_n\} \text{ is finite.}
\]

Let us check the basic properties of \(\sim\):
1. *Equivalence relation:*
   - *Reflexive:* \(\omega\) differs from \(\omega\) on \(\emptyset\), which is finite.
   - *Symmetric:* the set where \(\omega_n \ne \eta_n\) is the same as where \(\eta_n \ne \omega_n\).
   - *Transitive:* if \(\omega\) and \(\eta\) differ on a finite set \(F_1\), and \(\eta\) and \(\zeta\)
     differ on a finite set \(F_2\), then any coordinate where \(\omega_n \ne \zeta_n\) must belong to
     \(F_1 \cup F_2\), which is still finite.
2. *Countability of each equivalence class:* Fix \(\omega \in \Omega\). Every \(\eta \sim \omega\) is
   uniquely specified by the finite subset \(F = \{n \in \mathbb N : \eta_n \ne \omega_n\} \subseteq \mathbb N\)
   of coordinates where it differs from \(\omega\). How many finite subsets of \(\mathbb N\) exist?
   For each \(n \ge 1\), the subsets of \(\{1, \dots, n\}\) form a finite family (of size \(2^n\)), and
   every finite subset of \(\mathbb N\) is contained in \(\{1, \dots, n\}\) for some \(n\). A countable
   union of finite families is countable. Thus there are countably many finite subsets \(F \subseteq \mathbb N\),
   and each equivalence class is countable.

Using the *Axiom of Choice*, we select *exactly one* element from each equivalence class, and denote by
\(V \subseteq \Omega\) the set of selected representatives. (No formula or measurability is asserted
for this selection.)

For each finite subset \(F \subseteq \mathbb N\), define the bit-flip map \(T_F : \Omega \to \Omega\)
by flipping the bits in \(F\) and leaving all other coordinates unchanged:
\[
(T_F \omega)_n = \begin{cases} 1 - \omega_n, & \text{if } n \in F,\\ \omega_n, & \text{if } n \notin F. \end{cases}
\]

#+begin_quote
*Proposition 11.1.* The set \(V\) is not measurable even in the completion of the fair-coin
probability space.
#+end_quote

** Proof

We break the argument into three clear steps.

*Step 1. Flips preserve the probability measure (and its completion).*
Fix a finite subset \(F \subseteq \mathbb N\). Flipping the bits in \(F\) twice restores every bit to
its original value, so \(T_F \circ T_F = \mathrm{id}_\Omega\); in particular, \(T_F\) is a bijection and
is its own inverse (\(T_F^{-1} = T_F\), so \(T_F(A) = T_F^{-1}(A)\) for every subset \(A \subseteq \Omega\)).

What does \(T_F^{-1}\) do to an initial cylinder \(C = \{\omega : \omega_1 = a_1, \dots, \omega_m = a_m\}\)?
It simply flips the prescribed bits \(a_k\) for \(k \in F \cap \{1, \dots, m\}\), producing another
initial cylinder of the *exact same length \(m\)*:
\[
T_F^{-1}(C) = \{\omega : \omega_1 = b_1, \dots, \omega_m = b_m\}, \qquad
b_k = \begin{cases} 1 - a_k & (k \in F), \\ a_k & (k \notin F). \end{cases}
\]
Because initial cylinders generate the product \(\sigma\)-algebra \(\mathcal F\), the generator test
(Chapter 3) implies that \(T_F : (\Omega, \mathcal F) \to (\Omega, \mathcal F)\) is measurable.
Moreover, on any initial cylinder \(C\) of length \(m\), both \(C\) and \(T_F^{-1}(C)\) have fair-coin
probability \(2^{-m}\):
\[
((T_F)_\# \mathbb P)(C) = \mathbb P(T_F^{-1}(C)) = 2^{-m} = \mathbb P(C).
\]
Since initial cylinders (together with \(\emptyset\)) form a \(\pi\)-system generating \(\mathcal F\),
the uniqueness theorem for probability measures (Chapter 4) gives
\[
\mathbb P(T_F^{-1}(A)) = \mathbb P(A) \qquad \text{for all } A \in \mathcal F.
\]

Now let \((\Omega, \overline{\mathcal F}, \overline{\mathbb P})\) be the completion of the fair-coin
space (Proposition 5.14). Recall that \(E \in \overline{\mathcal F}\) iff \(E = A \cup N_0\) where
\(A \in \mathcal F\) and \(N_0 \subseteq N\) for some null set \(N \in \mathcal F\) with
\(\mathbb P(N) = 0\), and then \(\overline{\mathbb P}(E) = \mathbb P(A)\). Applying \(T_F^{-1}\) gives
\[
T_F^{-1}(E) = T_F^{-1}(A) \cup T_F^{-1}(N_0).
\]
Here \(T_F^{-1}(A) \in \mathcal F\) has measure \(\mathbb P(T_F^{-1}(A)) = \mathbb P(A)\), and
\(T_F^{-1}(N_0) \subseteq T_F^{-1}(N)\) where \(T_F^{-1}(N) \in \mathcal F\) has measure
\(\mathbb P(T_F^{-1}(N)) = \mathbb P(N) = 0\). Therefore \(T_F^{-1}(E) \in \overline{\mathcal F}\) and
\(\overline{\mathbb P}(T_F^{-1}(E)) = \overline{\mathbb P}(E)\). Since \(T_F = T_F^{-1}\), this also
says \(\overline{\mathbb P}(T_F(E)) = \overline{\mathbb P}(E)\).

*Step 2. The translates \(T_F(V)\) partition the space \(\Omega\).*
First, why do the sets \(T_F(V)\) cover \(\Omega\)? Take any \(\omega \in \Omega\). Its equivalence
class contains a unique selected representative \(v \in V\). Since \(\omega \sim v\), they differ on
some finite set \(F = \{n \in \mathbb N : \omega_n \ne v_n\}\). Flipping the bits of \(v\) on \(F\)
turns \(v\) into \(\omega\), so \(\omega = T_F(v) \in T_F(V)\).

Second, why are the sets \(T_F(V)\) pairwise disjoint as \(F\) ranges over all finite subsets of
\(\mathbb N\)? Suppose \(T_F(v) = T_G(w)\) for some \(v, w \in V\) and finite sets \(F, G \subseteq \mathbb N\).
- Both \(T_F(v)\) and \(v\) differ only on the finite set \(F\), so \(v \sim T_F(v)\). Similarly
  \(w \sim T_G(w)\). Since \(T_F(v) = T_G(w)\), transitivity gives \(v \sim w\). Because \(V\) contains
  *at most one* representative from each equivalence class, we must have \(v = w\).
- Now \(T_F(v) = T_G(v)\). If \(F \ne G\), pick a coordinate \(n\) that belongs to one of \(F, G\) but
  not the other (say \(n \in F \setminus G\)). Then \((T_F v)_n = 1 - v_n\) whereas \((T_G v)_n = v_n\),
  contradicting \(T_F(v) = T_G(v)\). Thus \(F = G\).

Hence the family \(\{T_F(V) : F \subseteq \mathbb N \text{ finite}\}\) is a countable pairwise disjoint
partition of \(\Omega\):
\[
\Omega = \bigsqcup_{F \subseteq \mathbb N \text{ finite}} T_F(V).
\]

*Step 3. Apply countable additivity to reach a contradiction.*
Suppose, for the sake of contradiction, that \(V \in \overline{\mathcal F}\) with probability
\(a := \overline{\mathbb P}(V) \in [0,1]\). By Step 1 (and \(T_F = T_F^{-1}\)), every translate
\(T_F(V)\) is also in \(\overline{\mathcal F}\) and has the exact same probability
\(\overline{\mathbb P}(T_F(V)) = a\). By Step 2 and countable additivity of \(\overline{\mathbb P}\),
\[
1 = \overline{\mathbb P}(\Omega) = \sum_{F \subseteq \mathbb N \text{ finite}} \overline{\mathbb P}(T_F(V))
= \sum_{F \subseteq \mathbb N \text{ finite}} a.
\]
- If \(a = 0\), the right-hand side is \(0 + 0 + \dots = 0 \ne 1\).
- If \(a > 0\), summing \(a\) over infinitely many finite sets \(F\) gives \(\infty \ne 1\) (already
  choosing \(N > 1/a\) disjoint translates gives probability \(N a > 1\)).

Both cases contradict \(\overline{\mathbb P}(\Omega) = 1\). Thus \(V \notin \overline{\mathcal F}\). \(\blacksquare\)

#+begin_quote
*Important lesson.* Completion adds all subsets of measurable null sets, which fixes bookkeeping
annoyances about negligible sets. It does *not* make every subset of \(\Omega\) measurable! Moreover,
Proposition 11.1 pinpoints the exact role of the Axiom of Choice: once the representatives \(V\) have
been chosen, the probability contradiction is completely elementary.
#+end_quote

** Additional worked examples and non-examples

*Example A (Visualizing \(T_F\) on initial cylinders).* Let \(F = \{1, 3\}\) and consider the cylinder
\(C = \{\omega \in \{0,1\}^{\mathbb N} : \omega_1 = 1,\ \omega_2 = 0,\ \omega_3 = 1\}\), which has
probability \(2^{-3} = 1/8\). Then \(\omega \in T_F^{-1}(C)\) iff \(T_{\{1,3\}}(\omega) \in C\), meaning
\(1 - \omega_1 = 1\), \(\omega_2 = 0\), and \(1 - \omega_3 = 1\). Thus
\[
T_{\{1,3\}}^{-1}(C) = \{\omega : \omega_1 = 0,\ \omega_2 = 0,\ \omega_3 = 0\},
\]
which is another initial cylinder of length \(3\), also of probability \(1/8\).

*Example B (Why this fails for biased coins — a non-example).* What if the coins are biased, with
\(\mathbb P(\omega_n = 1) = p \ne 1/2\)? The equivalence relation \(\sim\) and the partition
\(\Omega = \bigsqcup_F T_F(V)\) are purely set-theoretic, so they still hold. However, Step 1 fails:
flipping the first bit maps \(\{\omega_1 = 1\}\) (probability \(p\)) to \(\{\omega_1 = 0\}\)
(probability \(1-p\)), so \(T_F\) no longer preserves \(\mathbb P_p\). (In fact, \(V\) is still
nonmeasurable for \(\mathbb P_p\) when \(0 < p < 1\), by Kolmogorov's \(0\)–\(1\) law, which shows any
measurable tail-invariant set has probability \(0\) or \(1\), and even a single flip changes mass by a
bounded factor \((p/(1-p))^{\pm 1}\), so \(\mathbb P_p(V)=0 \implies \mathbb P_p(T_F V)=0\).)

*Example C (Why an explicit selection doesn't work).* Why did we need the Axiom of Choice to pick
\(V\)? In each equivalence class \([\omega]\), couldn't we just pick the "lexicographically smallest"
sequence? *No!* Take \(\omega = (1, 0, 1, 0, 1, 0, \dots)\). By flipping the first \(N\) ones to zeros,
we get sequences starting with arbitrarily many zeros, each strictly smaller in lexicographical order,
and the infimum \((0, 0, 0, \dots)\) differs from \(\omega\) in *infinitely* many coordinates so it
is not in \([\omega]\). No simple formula can choose a representative from every class.

* 11.2 What countably many coordinates can detect

** Intuition

Now let \(I\) be an arbitrary index set — think of \(I = [0,1]\) as continuous time — and consider the
space \(\mathbb R^I\) of all real-valued functions \(x : I \to \mathbb R\), written as coordinate
tuples \(x = (x_t)_{t \in I}\) or paths \(t \mapsto x(t)\).

Recall from Chapter 10 that the *product \(\sigma\)-algebra* \(\mathcal B(\mathbb R)^{\otimes I}\) on
\(\mathbb R^I\) is the smallest \(\sigma\)-algebra making every coordinate map \(\pi_t(x) = x(t)\)
measurable. Equivalently, it is generated by *finite-coordinate cylinder sets*, which only constrain
\(x(t_1), \dots, x(t_n)\) at finitely many times.

When we build more complicated sets out of cylinder sets using \(\sigma\)-algebra operations, each
step is a complement or a *countable* union. If set \(E_1\) looks at finitely many times, \(E_2\)
looks at finitely many times, \(E_3\) looks at finitely many times, and so on for a sequence
\(E_1, E_2, \dots\), then altogether \(\bigcup_{n=1}^\infty E_n\) only ever looks at a *countable*
union of finite sets of times — which is still a *countable* set of times!

#+begin_example
   Time interval I = [0, 1] (uncountably many times)
   |----*-------*--*--------*---------*------*----*-------|
        t_1    t_2 t_3     t_4       t_5    t_6  t_7 ...
        \___________________ ___________________________/
                            v
     Countable set J of times inspected by E in B(R)^{x I}.
     Pick ANY time t_0 NOT in J: changing x(t_0) cannot
     change whether x belongs to E!
#+end_example

Therefore, *no event in the product \(\sigma\)-algebra on \(\mathbb R^{[0,1]}\) can ever inspect all
times \(t \in [0,1]\)*. Every product-measurable event is completely blind to all coordinates outside
some countable subset \(J \subseteq I\).

** Formal definition and theorem

#+begin_quote
*Definition (Depending on a set of coordinates).* For a set \(E \subseteq \mathbb R^I\) and a subset
\(J \subseteq I\), we say that *membership in \(E\) depends on coordinates in \(J\)* if any two
functions \(x, y \in \mathbb R^I\) agreeing on \(J\) (i.e. \(x(t) = y(t)\) for all \(t \in J\)) either
both belong to \(E\) or both fail to belong to \(E\):
\[
\big(\forall t \in J,\ x(t) = y(t)\big) \quad \Longrightarrow \quad \big(\mathbf 1_E(x) = \mathbf 1_E(y)\big).
\]
#+end_quote

Note that this is purely a statement about membership in \(E\); it is *not* a new definition of
measurability. Also, if \(E\) depends on \(J\) and \(J \subseteq J'\), then \(E\) automatically
depends on \(J'\) as well (agreeing on \(J'\) implies agreeing on \(J\)).

#+begin_quote
*Proposition 11.2.* Every set in the product \(\sigma\)-algebra of \(\mathbb R^I\) depends on at most
countably many coordinates.
#+end_quote

** Proof

This is a classic "good sets principle" argument (Chapter 1). Let \(\mathcal H\) be the collection of
all subsets \(E \subseteq \mathbb R^I\) such that \(E\) depends on some countable (possibly finite or
empty) subset \(J \subseteq I\). We show that \(\mathcal H\) is a \(\sigma\)-algebra containing the
generators of the product \(\sigma\)-algebra.

1. *Whole space:* \(\mathbb R^I\) depends on the empty set \(J = \emptyset\) (which is countable),
   since every function belongs to \(\mathbb R^I\) regardless of its coordinate values. Thus
   \(\mathbb R^I \in \mathcal H\).
2. *Complements:* Suppose \(E \in \mathcal H\) depends on a countable set \(J \subseteq I\). If
   \(x, y \in \mathbb R^I\) agree on \(J\), then they either both belong to \(E\) or both fail to
   belong to \(E\) — which is the exact same thing as saying they either both fail to belong to \(E^c\)
   or both belong to \(E^c\). Thus \(E^c\) depends on the same countable set \(J\), so
   \(E^c \in \mathcal H\).
3. *Countable unions:* Suppose \(E_1, E_2, \dots \in \mathcal H\), where each \(E_n\) depends on a
   countable set \(J_n \subseteq I\). Let
   \[
   J := \bigcup_{n=1}^\infty J_n.
   \]
   Since a countable union of countable sets is countable, \(J\) is a countable subset of \(I\). Now
   suppose \(x, y \in \mathbb R^I\) agree on \(J\). For every \(n \ge 1\), since \(J_n \subseteq J\),
   \(x\) and \(y\) agree on \(J_n\); because \(E_n\) depends on \(J_n\), \(x\) and \(y\) have the same
   membership in \(E_n\). Therefore \(x \in \bigcup_{n=1}^\infty E_n\) if and only if
   \(y \in \bigcup_{n=1}^\infty E_n\). Thus \(\bigcup_{n=1}^\infty E_n\) depends on the countable set
   \(J\), so \(\bigcup_{n=1}^\infty E_n \in \mathcal H\).

This proves that \(\mathcal H\) is a \(\sigma\)-algebra on \(\mathbb R^I\). Finally, every
finite-coordinate cylinder set constrains only a finite set of coordinates
\(J = \{t_1, \dots, t_k\}\), which is countable, so \(\mathcal H\) contains all finite-coordinate
cylinders. Since those cylinders generate the product \(\sigma\)-algebra, the product
\(\sigma\)-algebra is contained in \(\mathcal H\). \(\blacksquare\)

#+begin_quote
*Caution (The converse is NOT true).* Proposition 11.2 is a one-way implication. A set depending on a
single coordinate \(t_0 \in I\) need not be in the product \(\sigma\)-algebra! For example, if
\(V \subseteq \mathbb R\) is a non-Borel Vitali set, then \(E = \{x \in \mathbb R^I : x(t_0) \in V\}\)
depends on the single coordinate \(J = \{t_0\}\), yet \(E\) is not product measurable (if it were, the
section/inclusion map \(r \mapsto (\text{constant function } r)\) would pull \(E\) back to \(V \in \mathcal B(\mathbb R)\)).
#+end_quote

** Examples from the notes

How do we use Proposition 11.2 in practice? To prove a subset \(E \subseteq \mathbb R^I\) is *not* in
the product \(\sigma\)-algebra, we play a two-move game against any proposed countable set \(J \subseteq I\):
- *Move 1:* Since \(I\) is uncountable and \(J\) is countable, pick a coordinate \(t \in I \setminus J\).
- *Move 2:* Exhibit two functions \(x, y \in \mathbb R^I\) that agree everywhere on \(J\) (in fact, agree
  at every coordinate except \(t\)), such that \(x \in E\) and \(y \notin E\).

#+begin_quote
*Example 11.3 (The zero path).* Take \(I = [0,1]\). The singleton \(\{0\}\) consisting of the
identically zero function \(0(s) \equiv 0\) is *not* product measurable. If it depended on a countable
set \(J \subseteq [0,1]\), choose \(t \notin J\) (possible since \([0,1]\) is uncountable). The zero
function \(x \equiv 0\) and the function \(y = \mathbf 1_{\{t\}}\) (equal to \(1\) at \(t\) and \(0\)
elsewhere) agree on \(J\), since \(t \notin J\). But \(x \in \{0\}\) whereas \(y \notin \{0\}\),
contradicting the proposed dependence on \(J\). Thus an uncountable intersection of measurable
single-coordinate events
\[
\{0\} = \bigcap_{t \in [0,1]} \{x \in \mathbb R^{[0,1]} : x(t) = 0\}
\]
need not be measurable.
#+end_quote

#+begin_quote
*Example 11.4 (The set of continuous paths).* The subset \(C([0,1]) \subseteq \mathbb R^{[0,1]}\) of
all continuous functions on \([0,1]\) is *not* product measurable either. For any countable
\(J \subseteq [0,1]\), choose \(t \in [0,1] \setminus J\). The identically zero path \(x \equiv 0\) is
continuous (\(x \in C([0,1])\)); the path \(y = \mathbf 1_{\{t\}}\) with a single spike of height \(1\)
at \(t\) is not continuous (\(y \notin C([0,1])\)), including when \(t = 0\) or \(t = 1\). Yet \(x\)
and \(y\) agree at every point of \(J\). Thus membership in \(C([0,1])\) cannot depend on \(J\), and
Proposition 11.2 implies \(C([0,1])\) is not in the product \(\sigma\)-algebra.
#+end_quote

Notice that Examples 11.3 and 11.4 are purely statements about the product \(\sigma\)-algebra on
\(\mathbb R^{[0,1]}\) *before* any probability measure is chosen. Whether a specific set becomes
measurable after completion depends on which probability measure we put on \(\mathbb R^{[0,1]}\) (for
instance, under the point mass \(\delta_0\) at the zero path, every subset of \(\mathbb R^{[0,1]} \setminus \{0\}\)
is a subset of a null set, or if \(\mu(C([0,1])^c)=0\) were somehow arranged; whereas Proposition 11.1
proved nonmeasurability in a *specific* completion).

** Additional worked examples and non-examples

*Example D (Bounded paths, monotone paths, Differentiable paths — all nonmeasurable).* By the exact
same spike trick on \(I = [0,1]\):
- The set of *bounded* functions \(B([0,1]) = \{x \in \mathbb R^{[0,1]} : \sup_{t \in [0,1]} |x(t)| \le 1\}\)
  is not product measurable: given a countable \(J \subseteq [0,1]\), pick \(t \notin J\) and compare
  \(x \equiv 0 \in B([0,1])\) with \(y = 2\,\mathbf 1_{\{t\}} \notin B([0,1])\).
- The set of *nondecreasing* functions on \([0,1]\) is not product measurable: given a countable
  \(J \subseteq [0,1]\), pick \(t \in (0,1) \setminus J\) and compare \(x \equiv 0\) (nondecreasing)
  with \(y = \mathbf 1_{\{t\}}\) (which jumps up from \(0\) to \(1\) at \(t\) and drops back to \(0\)
  for \(s > t\), so not nondecreasing).

*Example E (What IS product measurable on \(\mathbb R^{[0,1]}\)?).* Suppose we ask whether a path is
bounded at *rational* times:
\[
E = \Big\{x \in \mathbb R^{[0,1]} : \sup_{q \in \mathbb Q \cap [0,1]} |x(q)| \le 1\Big\}
  = \bigcap_{q \in \mathbb Q \cap [0,1]} \{x \in \mathbb R^{[0,1]} : |x(q)| \le 1\}.
\]
Since \(\mathbb Q \cap [0,1]\) is *countable*, \(E\) is a countable intersection of single-coordinate
Borel cylinders, so \(E\) *is* in the product \(\sigma\)-algebra! It depends on the countable set
\(J = \mathbb Q \cap [0,1]\).

* 11.3 Fixed times and whole paths

** Intuition

In probability, a continuous-time random phenomenon (such as the position of a diffusing particle or
the temperature in a room over time \(t \in [0,1]\)) is modeled as a *stochastic process*: a family of
random variables \((X_t)_{t \in I}\) defined on a common probability space \((\Omega, \mathcal F, \mathbb P)\).

There are two ways to view \(X_t(\omega)\) as a function of two variables \((t, \omega) \in I \times \Omega\):
1. *Fix the time \(t \in I\), vary the outcome \(\omega \in \Omega\):* we get the single-time random
   variable \(\omega \mapsto X_t(\omega)\).
2. *Fix the outcome \(\omega \in \Omega\), vary the time \(t \in I\):* we get a deterministic function
   of time \(t \mapsto X_t(\omega)\), called the *sample path* (or *trajectory*) of the outcome \(\omega\).

Because each coordinate \(X_t : \Omega \to \mathbb R\) is measurable, the universal property of product
\(\sigma\)-algebras (Chapter 10) tells us that the whole-path map
\[
\Phi : \Omega \longrightarrow \mathbb R^I, \qquad \omega \longmapsto (X_t(\omega))_{t \in I}
\]
is measurable into the product \(\sigma\)-algebra \(\mathcal B(\mathbb R)^{\otimes I}\).

*Here is the trap:* You might think that if two processes \((X_t)_{t \in [0,1]}\) and \((Y_t)_{t \in [0,1]}\)
satisfy \(\mathbb P(X_t = Y_t) = 1\) for *every single time \(t \in [0,1]\)*, then their sample paths
must agree with probability \(1\). *False!* For each fixed \(t\), the null set \(N_t = \{\omega : X_t(\omega) \ne Y_t(\omega)\}\)
has probability \(0\). But to say the *entire paths* agree is to stay outside \(\bigcup_{t \in [0,1]} N_t\),
which is an *uncountable* union of null sets — and an uncountable union of null sets can have
probability \(1\)!

#+begin_example
   Time t in [0,1]
     1 +-----------------------------------+
       |                                 / |  Y_t(omega) = 1 if t = omega,
       |                               /   |               0 otherwise.
       |                             /     |
     t | - - - - - - - - - - - - - *       |  <-- For fixed t: only hits spike at
       |                         / |       |      the single outcome omega = t
       |                       /   |       |      (Lebesgue measure 0!).
       |                     /     |       |
     0 +-------------------+-------+-------+  <-- For fixed omega: path t -> Y_t(omega)
       0                         omega     1      ALWAYS has a spike at t = omega!
                                                  Outcome omega in [0,1]
#+end_example

** The random spike example

#+begin_quote
*Example 11.5 (A random spike).* On the probability space \(([0,1], \mathcal B([0,1]), \lambda)\),
where \(\lambda\) is Lebesgue measure on \([0,1]\), define two stochastic processes indexed by
\(t \in [0,1]\):
\[
X_t(\omega) = 0, \qquad Y_t(\omega) = \mathbf 1_{\{t\}}(\omega) = \begin{cases} 1 & \text{if } \omega = t, \\ 0 & \text{if } \omega \ne t. \end{cases}
\]
- *At each fixed time \(t \in [0,1]\):* The event \(\{\omega \in [0,1] : X_t(\omega) \ne Y_t(\omega)\}\)
  is the singleton \(\{t\}\), which has Lebesgue measure \(\lambda(\{t\}) = 0\). Thus \(X_t = Y_t\)
  almost surely for every \(t \in [0,1]\).
- *At any finite list of times \(t_1, \dots, t_n \in [0,1]\):* The vectors \((X_{t_1}, \dots, X_{t_n})\)
  and \((Y_{t_1}, \dots, Y_{t_n})\) agree outside the finite null set \(\{t_1, \dots, t_n\}\). Thus
  \(X\) and \(Y\) have the *exact same finite-dimensional distributions* (every finite tuple is equal
  to \((0, \dots, 0)\) with probability \(1\)).
- *Along each sample path (fix \(\omega \in [0,1]\)):* Every sample path \(t \mapsto X_t(\omega) \equiv 0\)
  of \(X\) is identically zero and hence continuous. By contrast, for *every* outcome \(\omega \in [0,1]\),
  the sample path \(t \mapsto Y_t(\omega) = \mathbf 1_{\{\omega\}}(t)\) has a spike of height \(1\) at
  time \(t = \omega\) and is \(0\) everywhere else — so *every* sample path of \(Y\) is discontinuous!
  Indeed, there is *no* outcome \(\omega \in [0,1]\) on which the two paths agree at all times:
  \[
  \{\omega \in [0,1] : X_t(\omega) = Y_t(\omega) \text{ for all } t \in [0,1]\} = \emptyset.
  \]
#+end_quote

The invalid step that a careless reader might try is to intersect the uncountably many probability-one
events \(A_t = \{X_t = Y_t\} = [0,1] \setminus \{t\}\) over all \(t \in [0,1]\) and assume the
intersection \(\bigcap_{t \in [0,1]} A_t = \emptyset\) still has probability \(1\). Countable
additivity only guarantees that a *countable* intersection of probability-one events has probability
\(1\).

** Modifications versus indistinguishability

To keep this distinction crystal clear, probability theory uses two different terms:

#+begin_quote
*Definitions (Modifications and Indistinguishable processes).* Let \((X_t)_{t \in I}\) and
\((Y_t)_{t \in I}\) be two stochastic processes on the same probability space \((\Omega, \mathcal F, \mathbb P)\).
1. \(X\) and \(Y\) are *modifications* (or *versions*) of one another if they agree almost surely at
   each fixed time:
   \[
   \forall t \in I, \qquad \mathbb P(X_t = Y_t) = 1.
   \]
2. \(X\) and \(Y\) are *indistinguishable* if there is a single measurable probability-one event
   \(\Omega_0 \in \mathcal F\) with \(\mathbb P(\Omega_0) = 1\) on which their entire sample paths
   agree everywhere:
   \[
   \Omega_0 \subseteq \{\omega \in \Omega : X_t(\omega) = Y_t(\omega) \text{ for all } t \in I\}, \qquad \mathbb P(\Omega_0) = 1.
   \]
#+end_quote

Notice the order of quantifiers ("for all \(t\), almost surely" vs. "almost surely, for all \(t\)"):
- Indistinguishable \(\Longrightarrow\) modifications (since for each fixed \(t\), \(\{X_t = Y_t\} \supseteq \Omega_0\)).
- Modifications \(\not\Longrightarrow\) indistinguishable in general: in Example 11.5, \(X\) and
  \(Y\) are modifications of one another, but they are as far from indistinguishable as possible
  (they disagree on every path!).

** How path continuity rescues us (via a countable dense set)

Why did the random spike cause trouble? Because a spike at a single irrational time \(t = \omega\) is
invisible at all other times. What if we already know that *both* \(X\) and \(Y\) have *continuous*
sample paths?

Suppose \((X_t)_{t \in [0,1]}\) and \((Y_t)_{t \in [0,1]}\) are modifications of one another and that
for every \(\omega\), the functions \(t \mapsto X_t(\omega)\) and \(t \mapsto Y_t(\omega)\) are
continuous on \([0,1]\). Define the single event
\[
\Omega_0 := \bigcap_{q \in \mathbb Q \cap [0,1]} \{\omega \in \Omega : X_q(\omega) = Y_q(\omega)\}.
\]
- Because \(\mathbb Q \cap [0,1]\) is *countable* and each \(\{X_q = Y_q\}\) has probability \(1\),
  \(\Omega_0\) is a countable intersection of measurable probability-one events, so
  \(\Omega_0 \in \mathcal F\) and \(\mathbb P(\Omega_0) = 1\)!
- For any outcome \(\omega \in \Omega_0\), the two continuous functions \(t \mapsto X_t(\omega)\) and
  \(t \mapsto Y_t(\omega)\) agree at every rational time \(q \in \mathbb Q \cap [0,1]\). Since two
  continuous functions on \([0,1]\) that agree on a dense set must agree *everywhere* on \([0,1]\)
  (if \(t \in [0,1]\), pick rationals \(q_n \to t\); then \(X_t(\omega) = \lim X_{q_n}(\omega) = \lim Y_{q_n}(\omega) = Y_t(\omega)\)),
  we have \(X_t(\omega) = Y_t(\omega)\) for *all* \(t \in [0,1]\)!

#+begin_quote
*Takeaway.* Once path regularity (such as continuity, or right-continuity) is known, agreement at a
countable dense set of times \(\mathbb Q \cap [0,1]\) forces agreement at *all* times, upgrading
"modification" to "indistinguishable".
#+end_quote

* 11.4 Using continuous paths as the sample space

** Intuition

Wait a minute: Example 11.4 proved that \(C([0,1])\) is not a measurable subset of \(\mathbb R^{[0,1]}\).
How, then, can probabilists constantly talk about "random continuous paths" or put Wiener measure
(the law of Brownian motion) on \(C([0,1])\)?

The answer is simple: *stop putting \(C([0,1])\) inside the monstrous space \(\mathbb R^{[0,1]}\), and
instead use \(C([0,1])\) itself as the sample space!*

On \(C([0,1])\), every element \(f\) is *already* a continuous function on the compact interval
\([0,1]\). By a basic theorem of real analysis (Weierstrass's extreme value theorem), a continuous
function on \([0,1]\) is bounded and attains its maximum, so the *uniform norm* (or *supremum norm*)
\[
\|f\|_\infty := \sup_{0 \le t \le 1} |f(t)|
\]
is finite for every \(f \in C([0,1])\). (Be careful: here \(\|f\|_\infty\) is the *actual* pointwise
supremum over \(t \in [0,1]\), not the measure-theoretic essential supremum of Chapter 7 — though for
continuous functions on \([0,1]\) with Lebesgue measure, the two coincide.)

The distance \(\|f - g\|_\infty = \sup_{0 \le t \le 1} |f(t) - g(t)|\) measures the worst-case vertical
gap between the graphs of \(f\) and \(g\). An *open ball* with center \(g \in C([0,1])\) and radius
\(r > 0\) is a uniform "tube" of half-width \(r\) around the graph of \(g\):
\[
B(g, r) := \{f \in C([0,1]) : \|f - g\|_\infty < r\}.
\]

#+begin_example
       ^
       |          . . . . . . . . .          <-- g(t) + r
       |      . '   _______         ' .
       |    .     /         \           .    <-- f(t) stays strictly inside tube
       |   .     /   g(t)    \___________ .  <-- g(t) (center path)
       |        /
       |    . ' . . . . . . . . . . . . . '  <-- g(t) - r
       +------------------------------------> t
       0                                   1
#+end_example

A subset \(U \subseteq C([0,1])\) is *open* for the uniform norm if around each \(g \in U\) it contains
some open ball \(B(g, r) \subseteq U\). The *Borel \(\sigma\)-algebra* \(\mathcal B(C([0,1]))\) is the
\(\sigma\)-algebra on \(C([0,1])\) generated by all open subsets.

At first glance, \(\mathcal B(C([0,1]))\) looks huge (generated by open tubes around arbitrary
continuous functions) while coordinate evaluations \(f \mapsto f(q)\) at rational times look tiny.
Remarkably, Proposition 11.6 shows that *they generate the exact same \(\sigma\)-algebra*!

** The theorem on the Borel \(\sigma\)-algebra of \(C([0,1])\)

#+begin_quote
*Proposition 11.6.* The Borel \(\sigma\)-algebra of \(C([0,1])\) for the uniform norm is generated by
the evaluation maps \(\pi_q : f \mapsto f(q)\) at rational \(q \in \mathbb Q \cap [0,1]\).
#+end_quote

** Proof

Let \(\mathcal B = \mathcal B(C([0,1]))\) be the Borel \(\sigma\)-algebra on \(C([0,1])\), and let
\(\mathcal E := \sigma(\pi_q : q \in \mathbb Q \cap [0,1])\) be the \(\sigma\)-algebra generated by the
rational point evaluations. We must prove \(\mathcal E = \mathcal B\) by showing both inclusions
\(\mathcal E \subseteq \mathcal B\) and \(\mathcal B \subseteq \mathcal E\).

*Inclusion 1 (\(\mathcal E \subseteq \mathcal B\)): Every rational evaluation is continuous, hence Borel measurable.*
Fix \(q \in \mathbb Q \cap [0,1]\). For any \(f, g \in C([0,1])\), the difference at a single point
\(q\) is at most the supremum over all points:
\[
\lvert\pi_q(f) - \pi_q(g)\rvert = \lvert f(q) - g(q)\rvert \le \sup_{0 \le t \le 1} \lvert f(t) - g(t)\rvert = \|f - g\|_\infty.
\]
Thus if \(\|f - g\|_\infty < \varepsilon\), then \(|\pi_q(f) - \pi_q(g)| < \varepsilon\), so
\(\pi_q : C([0,1]) \to \mathbb R\) is continuous. The preimage of any open set in \(\mathbb R\) under a
continuous map is open in \(C([0,1])\), hence in \(\mathcal B\). By the generator test, each \(\pi_q\)
is \(\mathcal B\)-measurable, and since \(\mathcal E\) is the smallest \(\sigma\)-algebra making all
\(\pi_q\) measurable, \(\mathcal E \subseteq \mathcal B\).

*Inclusion 2 (\(\mathcal B \subseteq \mathcal E\)): Every open set in \(C([0,1])\) belongs to \(\mathcal E\).*
Since \(\mathcal B\) is generated by the open sets of \(C([0,1])\), it suffices to show that every open
set \(U \subseteq C([0,1])\) belongs to \(\mathcal E\). We do this in three sub-steps: closed balls
\(\to\) open balls \(\to\) arbitrary open sets via a countable dense family of piecewise linear paths
(showing \(C([0,1])\) is *separable*).

- *Sub-step 2a (Closed balls belong to \(\mathcal E\)).* Fix any center \(g \in C([0,1])\) and radius
  \(r \ge 0\). For any \(f \in C([0,1])\), the function \(t \mapsto |f(t) - g(t)|\) is continuous on
  \([0,1]\). Since \(\mathbb Q \cap [0,1]\) is dense in \([0,1]\), the supremum over \([0,1]\) equals
  the supremum over rational times:
  \[
  \|f - g\|_\infty = \sup_{0 \le t \le 1} |f(t) - g(t)| = \sup_{q \in \mathbb Q \cap [0,1]} |f(q) - g(q)|.
  \]
  (Why? The inequality \(\ge\) is trivial because \(\mathbb Q \cap [0,1] \subseteq [0,1]\). For \(\le\),
  take any \(t \in [0,1]\) and choose rationals \(q_n \in \mathbb Q \cap [0,1]\) with \(q_n \to t\);
  continuity of \(f - g\) gives \(|f(t) - g(t)| = \lim_{n\to\infty} |f(q_n) - g(q_n)| \le \sup_{q \in \mathbb Q \cap [0,1]} |f(q) - g(q)|\).)

  Consequently, \(\|f - g\|_\infty \le r\) holds if and only if \(|f(q) - g(q)| \le r\) holds for
  *every* \(q \in \mathbb Q \cap [0,1]\). That expresses the closed ball \(\overline B(g, r)\) as a
  *countable* intersection of sets in \(\mathcal E\):
  \[
  \overline B(g, r) = \{f \in C([0,1]) : \|f - g\|_\infty \le r\}
  = \bigcap_{q \in \mathbb Q \cap [0,1]} \underbrace{\{f \in C([0,1]) : |\pi_q(f) - g(q)| \le r\}}_{\in \mathcal E, \text{ since } [g(q)-r,\, g(q)+r] \in \mathcal B(\mathbb R)}.
  \]
  Hence every closed ball \(\overline B(g, r)\) belongs to \(\mathcal E\).

- *Sub-step 2b (Open balls belong to \(\mathcal E\)).* Fix \(g \in C([0,1])\) and \(r > 0\). A number
  \(d = \|f - g\|_\infty\) satisfies \(d < r\) if and only if \(d \le r - 1/n\) for some integer
  \(n \ge 1\) with \(r - 1/n > 0\). Thus the open ball \(B(g, r)\) is a countable union of closed balls:
  \[
  B(g, r) = \{f \in C([0,1]) : \|f - g\|_\infty < r\}
  = \bigcup_{n \ge 1:\ r - 1/n > 0} \overline B(g, r - 1/n) \in \mathcal E.
  \]

- *Sub-step 2c (Countable dense family of rational piecewise linear functions).* An arbitrary open set
  \(U \subseteq C([0,1])\) is a union of open balls around its points, \(\bigcup_{f \in U} B(f, \varepsilon_f)\),
  which is an *uncountable* union! To write \(U\) as a *countable* union of open balls, we construct a
  countable dense subset \(\mathcal D \subseteq C([0,1])\) (just like \(\mathbb Q^d\) was used in
  \(\mathbb R^d\)).

  Let \(\mathcal D\) be the collection of all *piecewise linear functions* on \([0,1]\) that have:
  1. finitely many breakpoints \(0 = q_0 < q_1 < \dots < q_m = 1\), all *rational* (\(q_j \in \mathbb Q \cap [0,1]\)), and
  2. *rational* values \(y_j = g(q_j) \in \mathbb Q\) at each breakpoint, with linear interpolation on
     each subinterval \([q_{j-1}, q_j]\).

  Why is \(\mathcal D\) countable? Each function in \(\mathcal D\) is completely specified by a finite
  list of rational numbers \((q_0, q_1, \dots, q_m;\, y_0, y_1, \dots, y_m)\). For each fixed integer
  \(m \ge 1\), the set \(\mathbb Q^{2m+2}\) is countable (finite product of countable sets), and taking
  the union over \(m \in \mathbb N\) gives a countable union of countable sets, which is countable.

  Why is \(\mathcal D\) dense in \((C([0,1]), \|\cdot\|_\infty)\)? Fix any \(f \in C([0,1])\) and
  \(\varepsilon > 0\).
  1. Since \(f\) is continuous on the compact interval \([0,1]\), \(f\) is *uniformly continuous* on
     \([0,1]\). Choose a rational grid \(0 = q_0 < q_1 < \dots < q_m = 1\) fine enough that on each
     subinterval \([q_{j-1}, q_j]\), the oscillation of \(f\) is less than \(\varepsilon/2\):
     \[
     \lvert f(t) - f(s)\rvert < \frac{\varepsilon}{2} \qquad \text{for all } t, s \in [q_{j-1}, q_j].
     \]
  2. Let \(L\) be the piecewise linear function that interpolates the exact endpoint values
     \(f(q_0), \dots, f(q_m)\) linearly on each \([q_{j-1}, q_j]\). For any \(t \in [q_{j-1}, q_j]\),
     the linearly interpolated value \(L(t)\) is a convex combination
     \(L(t) = (1-\alpha) f(q_{j-1}) + \alpha f(q_j)\) (with \(\alpha \in [0,1]\)), so \(L(t)\) lies
     between \(f(q_{j-1})\) and \(f(q_j)\). Since \(f(t)\) differs from both \(f(q_{j-1})\) and
     \(f(q_j)\) by less than \(\varepsilon/2\), it also differs from any number between them by less
     than \(\varepsilon/2\):
     \[
     \lvert f(t) - L(t)\rvert < \frac{\varepsilon}{2} \qquad \text{for all } t \in [0,1], \quad \text{so } \|f - L\|_\infty < \frac{\varepsilon}{2}.
     \]
  3. Finally, for each breakpoint \(q_j\), pick a rational number \(y_j \in \mathbb Q\) with
     \(|y_j - f(q_j)| < \varepsilon/2\), and let \(g \in \mathcal D\) be the piecewise linear function
     with values \(y_j\) at \(q_j\). On each interval \([q_{j-1}, q_j]\), the difference \(L(t) - g(t)\)
     is linear, so its maximum absolute value occurs at one of the endpoints \(q_{j-1}\) or \(q_j\) and
     is strictly less than \(\varepsilon/2\). Thus \(\|L - g\|_\infty < \varepsilon/2\).
  4. By the triangle inequality,
     \[
     \|f - g\|_\infty \le \|f - L\|_\infty + \|L - g\|_\infty < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.
     \]

- *Sub-step 2d (Every open set is a countable union of rational balls).* Let \(\mathcal C\) be the
  family of all open balls \(B(g, r)\) with center \(g \in \mathcal D\) and positive rational radius
  \(r \in \mathbb Q \cap (0, \infty)\). Since \(\mathcal D\) and \(\mathbb Q \cap (0, \infty)\) are both
  countable, \(\mathcal C\) is a *countable* family of open balls, and by Sub-step 2b every ball in
  \(\mathcal C\) belongs to \(\mathcal E\).

  Now let \(U \subseteq C([0,1])\) be any open set. We claim that \(U\) is the union of those balls in
  \(\mathcal C\) that are contained in \(U\):
  \[
  U = \bigcup \{B(g, r) \in \mathcal C : B(g, r) \subseteq U\}.
  \]
  The inclusion \(\supseteq\) is immediate since every ball in the union is a subset of \(U\). For
  \(\subseteq\), take any \(f \in U\). Because \(U\) is open, there is some \(\varepsilon > 0\) such
  that \(B(f, \varepsilon) \subseteq U\). By density of \(\mathcal D\), choose \(g \in \mathcal D\) with
  \(\|f - g\|_\infty < \varepsilon/4\), and choose a rational radius \(r \in \mathbb Q \cap (\varepsilon/4, \varepsilon/2)\).
  Then:
  1. \(f \in B(g, r)\) because \(\|f - g\|_\infty < \varepsilon/4 < r\).
  2. \(B(g, r) \subseteq B(f, \varepsilon) \subseteq U\) because for any \(h \in B(g, r)\), the
     triangle inequality gives
     \[
     \|h - f\|_\infty \le \|h - g\|_\infty + \|g - f\|_\infty < r + \frac{\varepsilon}{4} < \frac{\varepsilon}{2} + \frac{\varepsilon}{4} < \varepsilon.
     \]
  Thus \(U\) is a countable union of members of \(\mathcal E\), so \(U \in \mathcal E\). This completes
  the proof that \(\mathcal B \subseteq \mathcal E\). \(\blacksquare\)

** Examples from the notes

#+begin_quote
*Example 11.7 (The maximum of a continuous path).* On the path space \((C([0,1]), \mathcal B(C([0,1])))\),
the running-maximum functional
\[
M : C([0,1]) \longrightarrow \mathbb R, \qquad M(f) := \sup_{0 \le t \le 1} f(t)
\]
is measurable. Indeed, by continuity of \(f\) and density of \(\mathbb Q \cap [0,1]\) in \([0,1]\),
\[
M(f) = \sup_{0 \le t \le 1} f(t) = \sup_{q \in \mathbb Q \cap [0,1]} f(q) = \sup_{q \in \mathbb Q \cap [0,1]} \pi_q(f),
\]
which is a *countable* supremum of measurable evaluation maps! In particular, for every \(a \in \mathbb R\),
\[
\Big\{f \in C([0,1]) : \sup_{0 \le t \le 1} f(t) > a\Big\}
= \bigcup_{q \in \mathbb Q \cap [0,1]} \{f \in C([0,1]) : f(q) > a\}.
\]
Notice why the strict inequality \(> a\) is so convenient here: if a continuous function \(f\) achieves
a value strictly above \(a\) at some time \(t \in [0,1]\), then by continuity \(f(s) > a\) on a whole
open interval around \(t\) in \([0,1]\), so \(f(q) > a\) is also witnessed at a rational time
\(q \in \mathbb Q \cap [0,1]\). (Actually, the map \(f \mapsto \sup_t f(t)\) is even \(1\)-Lipschitz in
the uniform norm, since \(|\sup_t f(t) - \sup_t g(t)| \le \|f - g\|_\infty\), which gives a second proof
of Borel measurability!)
#+end_quote

** Viewing a continuous-path process as a \(C([0,1])\)-valued random variable

Suppose \((X_t)_{t \in [0,1]}\) is a stochastic process on \((\Omega, \mathcal F, \mathbb P)\) that is
known to have continuous sample paths on a measurable probability-one event \(\Omega_0 \in \mathcal F\)
(\(\mathbb P(\Omega_0) = 1\)).
1. On the negligible exceptional set \(\Omega \setminus \Omega_0\), redefine \(X_t(\omega) := 0\) for
   all \(t \in [0,1]\) (the zero path). Then *every* \(\omega \in \Omega\) produces a continuous path
   \(\widetilde X(\omega) \in C([0,1])\), and \(\widetilde X\) is indistinguishable from \(X\).
2. Is the path map \(\widetilde X : (\Omega, \mathcal F) \to (C([0,1]), \mathcal B(C([0,1])))\)
   measurable? By Proposition 11.6 and the generator test (Chapter 3), \(\widetilde X\) is measurable
   into \(\mathcal B(C([0,1]))\) if and only if \(\pi_q \circ \widetilde X = \widetilde X_q : \Omega \to \mathbb R\)
   is measurable for every rational \(q \in \mathbb Q \cap [0,1]\) — which holds automatically because
   each \(\widetilde X_q\) is a random variable!

#+begin_quote
*Crucial caveat.* Constructing such a continuous modification \(\widetilde X\) in the first place (e.g.
for Brownian motion via Kolmogorov's continuity theorem) requires genuine analytical work on the moments
or increments of \(X_t - X_s\). As Example 11.5 (the random spike) showed, specifying consistent
finite-dimensional distributions does *not* automatically make the sample paths continuous!
#+end_quote

** Additional worked examples

*Example F (Time integrals and hitting levels on \(C([0,1])\)).* Once we work on \((C([0,1]), \mathcal B(C([0,1])))\),
many path functionals become manifestly measurable:
- *Definite integral of the path:* \(I(f) := \int_0^1 f(t)\,dt\). Since \(|I(f) - I(g)| \le \int_0^1 |f(t) - g(t)|\,dt \le \|f - g\|_\infty\),
  \(I : C([0,1]) \to \mathbb R\) is continuous in the uniform norm, hence Borel measurable! Equivalently,
  it is the pointwise limit of Riemann sums \(\frac{1}{n}\sum_{k=1}^n \pi_{k/n}(f)\), which only use
  rational evaluations.
- *First hitting time of an open set:* For \(a \in \mathbb R\), when does a path \(f \in C([0,1])\)
  strictly exceed \(a\) before time \(t_0 \in (0,1]\)? By continuity,
  \[
  \Big\{f \in C([0,1]) : \sup_{0 \le t \le t_0} f(t) > a\Big\}
  = \bigcup_{q \in \mathbb Q \cap [0, t_0]} \{f \in C([0,1]) : f(q) > a\} \in \mathcal B(C([0,1])).
  \]

** Historical remark (Doob, 1937)

In 1937, Joseph L. Doob explicitly identified the foundational difficulty of continuous-time path spaces
in his landmark paper /Stochastic processes depending on a continuous parameter/ (/Transactions of the
American Mathematical Society/ 42 (1937), p. 108): specifying consistent probabilities at finitely many
times (as in Kolmogorov's extension theorem) only defines a probability measure on the product
\(\sigma\)-algebra of \(\mathbb R^{[0,1]}\), which does *not* assign a probability to the set
\(C([0,1])\) of continuous paths. Doob's paper launched the modern theory of separable processes and
modifications to allow path properties to be studied rigorously. (Our random-spike Example 11.5 is a
modern pedagogical illustration of the distinction between fixed-time agreement and whole-path agreement,
rather than an example from Doob's 1937 paper.)

* Worked Exercises

** Exercise 1
Let \(I = [0,1]\) and consider the subset of \(\mathbb R^{[0,1]}\) consisting of all paths that vanish
at every rational time:
\[
E_1 = \{x \in \mathbb R^{[0,1]} : x(q) = 0 \text{ for all } q \in \mathbb Q \cap [0,1]\},
\]
and the subset of paths that vanish at every *irrational* time:
\[
E_2 = \{x \in \mathbb R^{[0,1]} : x(t) = 0 \text{ for all } t \in [0,1] \setminus \mathbb Q\}.
\]
Determine whether \(E_1\) and \(E_2\) belong to the product \(\sigma\)-algebra \(\mathcal B(\mathbb R)^{\otimes [0,1]}\).

** Solution
- *\(E_1\) is product measurable:* We can write
  \[
  E_1 = \bigcap_{q \in \mathbb Q \cap [0,1]} \pi_q^{-1}(\{0\}).
  \]
  Each \(\pi_q^{-1}(\{0\})\) is a single-coordinate Borel cylinder, and \(\mathbb Q \cap [0,1]\) is
  countable, so \(E_1\) is a countable intersection of product-measurable sets.
- *\(E_2\) is NOT product measurable:* Suppose \(E_2\) were in the product \(\sigma\)-algebra. By
  Proposition 11.2, membership in \(E_2\) would depend on some countable set \(J \subseteq [0,1]\).
  Since \([0,1] \setminus \mathbb Q\) is uncountable (otherwise \([0,1] = (\mathbb Q \cap [0,1]) \cup ([0,1] \setminus \mathbb Q)\)
  would be a union of two countable sets, hence countable) and \(J\) is countable, the set
  \(([0,1] \setminus \mathbb Q) \setminus J\) is nonempty. Pick an irrational \(t_0 \in ([0,1] \setminus \mathbb Q) \setminus J\).
  Compare the zero function \(x \equiv 0\) with the spike function \(y = \mathbf 1_{\{t_0\}}\):
  - \(x\) and \(y\) agree on \(J\) because \(t_0 \notin J\).
  - \(x \in E_2\) (it is zero everywhere), whereas \(y \notin E_2\) because \(y(t_0) = 1 \ne 0\) at the
    irrational point \(t_0\).
  This contradicts dependence on \(J\), so \(E_2\) is not product measurable.

** Exercise 2
Show that the set of Riemann integrable functions \(R([0,1]) \subseteq \mathbb R^{[0,1]}\) does *not*
belong to the product \(\sigma\)-algebra \(\mathcal B(\mathbb R)^{\otimes [0,1]}\).

** Solution
Suppose \(R([0,1])\) belonged to the product \(\sigma\)-algebra. By Proposition 11.2, membership in
\(R([0,1])\) would depend on some countable subset \(J \subseteq [0,1]\). Recall that every Riemann
integrable function on \([0,1]\) is *bounded* by definition. Since \([0,1] \setminus J\) is uncountable,
we can choose a sequence of distinct points \(t_1, t_2, \dots \in [0,1] \setminus J\). Define two
functions \(x, y \in \mathbb R^{[0,1]}\):
- \(x(t) = 0\) for all \(t \in [0,1]\), which is continuous and hence Riemann integrable (\(x \in R([0,1])\)).
- \(y(t_n) = n\) for each \(n \ge 1\), and \(y(t) = 0\) for all \(t \notin \{t_1, t_2, \dots\}\). Since
  \(y\) is unbounded on \([0,1]\), \(y\) is not Riemann integrable (\(y \notin R([0,1])\)).
However, since \(\{t_1, t_2, \dots\} \cap J = \emptyset\), we have \(x(t) = 0 = y(t)\) for all
\(t \in J\). This contradicts dependence on \(J\). Thus \(R([0,1]) \notin \mathcal B(\mathbb R)^{\otimes [0,1]}\).

** Exercise 3
On \(([0,1], \mathcal B([0,1]), \lambda)\), define \(X_t(\omega) = 0\) and \(Z_t(\omega) = \mathbf 1_{\mathbb Q}(t - \omega)\)
for \(t \in [0,1]\).
1. Are \(X\) and \(Z\) modifications of one another?
2. Are \(X\) and \(Z\) indistinguishable?

** Solution
1. *Yes, \(X\) and \(Z\) are modifications:* Fix any \(t \in [0,1]\). Then \(Z_t(\omega) \ne X_t(\omega) = 0\)
   if and only if \(t - \omega \in \mathbb Q\), i.e. \(\omega \in (t - \mathbb Q) \cap [0,1]\). Since
   \(t - \mathbb Q\) is countable, its Lebesgue measure is \(\lambda((t - \mathbb Q) \cap [0,1]) = 0\).
   Thus \(\lambda(\{X_t = Z_t\}) = 1\) for every fixed \(t \in [0,1]\).
2. *No, \(X\) and \(Z\) are not indistinguishable:* Fix *any* outcome \(\omega \in [0,1]\). Since
   \(\mathbb Q\) is dense in \(\mathbb R\), there exists \(q \in \mathbb Q\) such that
   \(t := \omega + q \in [0,1]\) (in fact, infinitely many such \(t\)). At that time \(t\),
   \(t - \omega = q \in \mathbb Q\), so \(Z_t(\omega) = 1 \ne 0 = X_t(\omega)\). Thus the set of
   outcomes where the two paths agree at all times is the *empty set* \(\emptyset\), which has measure
   \(0\), not \(1\).

** Exercise 4
Let \((X_t)_{t \in [0,1]}\) and \((Y_t)_{t \in [0,1]}\) be two stochastic processes on
\((\Omega, \mathcal F, \mathbb P)\) that are modifications of one another. Suppose that for every
\(\omega \in \Omega\), both sample paths \(t \mapsto X_t(\omega)\) and \(t \mapsto Y_t(\omega)\) are
*right-continuous* on \([0,1]\) (as happens for Poisson processes and cumulative distribution functions).
Prove that \(X\) and \(Y\) are indistinguishable.

** Solution
Define the countable set \(D := (\mathbb Q \cap [0,1]) \cup \{1\}\) (note \(1 \in \mathbb Q \cap [0,1]\)
already). For each \(q \in D\), since \(X\) and \(Y\) are modifications, the measurable event
\(A_q := \{\omega \in \Omega : X_q(\omega) = Y_q(\omega)\}\) satisfies \(\mathbb P(A_q) = 1\). Let
\[
\Omega_0 := \bigcap_{q \in D} A_q.
\]
Since \(D\) is countable, \(\Omega_0 \in \mathcal F\) and \(\mathbb P(\Omega_0) = 1\).

Now take any \(\omega \in \Omega_0\) and any time \(t \in [0,1]\).
- If \(t = 1\), then \(1 \in D\) so \(X_1(\omega) = Y_1(\omega)\) directly from \(\omega \in A_1\).
- If \(0 \le t < 1\), choose a sequence of rational numbers \(q_n \in \mathbb Q \cap (t, 1]\) decreasing
  to \(t\) (\(q_n \downarrow t\)). Since \(\omega \in \Omega_0\), we have \(X_{q_n}(\omega) = Y_{q_n}(\omega)\)
  for every \(n\). Passing to the limit as \(n \to \infty\) and using right-continuity of both sample
  paths at \(t\) gives
  \[
  X_t(\omega) = \lim_{n \to \infty} X_{q_n}(\omega) = \lim_{n \to \infty} Y_{q_n}(\omega) = Y_t(\omega).
  \]
Thus \(\Omega_0 \subseteq \{\omega \in \Omega : X_t(\omega) = Y_t(\omega) \text{ for all } t \in [0,1]\}\)
with \(\mathbb P(\Omega_0) = 1\), so \(X\) and \(Y\) are indistinguishable.

** Exercise 5
On \((C([0,1]), \mathcal B(C([0,1])))\), show that the set of nondecreasing continuous functions
\[
M_\uparrow := \{f \in C([0,1]) : f(s) \le f(t) \text{ whenever } 0 \le s \le t \le 1\}
\]
is a Borel subset of \(C([0,1])\). Contrast this with Exercise D in Section 11.2!

** Solution
Because every \(f \in C([0,1])\) is continuous, \(f(s) \le f(t)\) holds for all \(0 \le s \le t \le 1\)
if and only if \(f(p) \le f(q)\) holds for all *rational* pairs \(p, q \in \mathbb Q \cap [0,1]\) with
\(p \le q\). (Indeed, if \(0 \le s \le t \le 1\), choose rationals \(p_n, q_n \in \mathbb Q \cap [0,1]\)
with \(p_n \le q_n\), \(p_n \to s\), and \(q_n \to t\); then \(f(p_n) \le f(q_n)\) passes to the limit
by continuity to give \(f(s) \le f(t)\).) Therefore
\[
M_\uparrow = \bigcap_{\substack{p, q \in \mathbb Q \cap [0,1] \\ p \le q}} \{f \in C([0,1]) : \pi_p(f) - \pi_q(f) \le 0\}.
\]
There are only *countably many* pairs \((p, q)\) of rationals in \([0,1]\) with \(p \le q\), and for
each pair the map \(\pi_p - \pi_q : C([0,1]) \to \mathbb R\) is Borel measurable by Proposition 11.6.
Hence \(M_\uparrow\) is a countable intersection of Borel sets, so \(M_\uparrow \in \mathcal B(C([0,1]))\).
(In \(\mathbb R^{[0,1]}\), where paths are not assumed continuous, a single irrational spike could
destroy monotonicity while remaining invisible to all rational coordinates!)

** Exercise 6
In the setting of Section 11.1, let \(E \subseteq \{0,1\}^{\mathbb N}\) be any set in the completed
fair-coin \(\sigma\)-algebra \(\overline{\mathcal F}\) that is invariant under all finite bit flips,
meaning \(T_F(E) = E\) for every finite \(F \subseteq \mathbb N\) (for example, the event
\(\{\omega : \lim_{n\to\infty} \frac{1}{n}\sum_{k=1}^n \omega_k = 1/2\}\)). Could such a set \(E\) be a
single equivalence class \([\omega_0]\) of \(\sim\)? Compute \(\overline{\mathbb P}([\omega_0])\).

** Solution
Every single equivalence class \([\omega_0] = \{T_F(\omega_0) : F \subseteq \mathbb N \text{ finite}\}\)
is a *countable* set of singletons \(\{\eta\}\). In the fair-coin space, each singleton
\(\{\eta\} = \bigcap_{n=1}^\infty \{\omega : \omega_n = \eta_n\}\) belongs to \(\mathcal F\) and has
probability \(\lim_{n\to\infty} 2^{-n} = 0\). Therefore every equivalence class \([\omega_0]\) is a
countable union of measurable null singletons, so \([\omega_0] \in \mathcal F \subseteq \overline{\mathcal F}\)
with \(\mathbb P([\omega_0]) = \sum_{\eta \in [\omega_0]} 0 = 0\)!

Note the contrast with \(V\):
- Each *equivalence class* \([\omega_0]\) picks *all* countably many elements along a single orbit of
  \(T_F\) (vertical slice) and is a Borel set of probability \(0\).
- The nonmeasurable choice set \(V\) picks *one* element from each of the uncountably many orbits
  (horizontal cross-section), and its countably many translates \(T_F(V)\) tile \(\Omega\).

*Key takeaways*

- A \(\sigma\)-algebra is an essential part of a probability model, not a technicality that disappears
  after completion (Proposition 11.1).
- In an uncountable product \(\mathbb R^I\), every product-measurable event depends on at most countably
  many coordinates (Proposition 11.2). To prove a set of paths is *not* product measurable, pick a time
  \(t \notin J\) outside an arbitrary countable set \(J\) and insert a spike at \(t\) (Examples 11.3–11.4).
- Almost-sure agreement at each fixed time (modification) does *not* imply almost-sure agreement of whole
  paths (indistinguishability), because an uncountable union of null sets need not be null (Example 11.5).
- For processes with continuous (or right-continuous) paths, checking countably many rational times
  \(\mathbb Q \cap [0,1]\) suffices both to upgrade modifications to indistinguishable processes and to
  generate the uniform-norm Borel \(\sigma\)-algebra on \(C([0,1])\) (Proposition 11.6).
