* Overview

** What problem does this chapter solve?

A measurable function can be wild. The indicator of the rationals, \(\mathbf 1_{\mathbb Q}\), is
discontinuous at every point; the indicator of a "fat Cantor set" jumps on a set of positive length.
Pointwise, such functions look nothing like the continuous functions of calculus. Yet in practice we
constantly want to replace a messy function by a nice one: to prove an inequality for smooth
functions and then pass to the limit, to compute an expectation numerically, or to show that two
measures are equal because they integrate all smooth functions the same way.

This chapter shows that on Euclidean space \(\mathbb R^d\) this replacement is always possible
*in an averaged sense*:

1. *Sets.* Every Borel set \(E\) can be squeezed between a compact set \(K\) inside it and an open set
   \(U\) around it, with \(\mu(U\setminus K)\) as small as we like (Theorem 8.1, "regularity").
2. *Bump functions.* Between any compact \(K\) and open \(U \supseteq K\) we can fit a smooth function
   that equals \(1\) on \(K\) and vanishes outside \(U\) (Lemma 8.3).
3. *Functions.* Combining 1 and 2, every \(f \in L^p(\mu)\) with \(1 \le p < \infty\) is the
   \(L^p\)-limit of smooth compactly supported functions (Theorem 8.4). For \(p=\infty\) this fails
   (Example 8.6).
4. *Without moments.* Even functions with no finite moment can be approximated *in measure*
   (Proposition 8.7).

An important feature: the measure \(\mu\) does *not* have to be Lebesgue measure. It may have atoms
(point masses), like the law of a die roll viewed as a measure on \(\mathbb R\). The approximation
must then respect \(\mu\), not Lebesgue measure (Example 8.5).

** Probability motivation

If \(X\) is a random vector in \(\mathbb R^d\) with law \(\mu\), Theorem 8.1 says: for any event
\(\{X \in E\}\), we can find a compact \(K \subseteq E\) with \(\mathbb P(X \in E \setminus K)\)
tiny. "Up to a small probability, the random vector lives in a bounded closed region." Theorem 8.4
says that expectations \(\mathbb E[f(X)]\) of rough functions are limits of expectations of smooth
functions, which is the starting point of many arguments about convergence in distribution
(Chapter 14).

** Euclidean facts used freely

These come from real analysis, not measure theory:

- A subset of \(\mathbb R^d\) is compact iff it is closed and bounded.
- Every open cover of a compact set has a finite subcover.
- Every sequence in a compact set has a subsequence converging to a point of that set.
- A decreasing sequence of nonempty compact sets has nonempty intersection.
- A continuous function on a compact set is bounded and uniformly continuous.

** Standing conventions

Throughout, \(d \ge 1\), \(\mathcal B(\mathbb R^d)\) is the \(\sigma\)-algebra generated by the
open subsets of \(\mathbb R^d\), and a *Borel measure* is a measure on \(\mathcal B(\mathbb R^d)\).

#+begin_quote
*Definition (locally finite).* A Borel measure \(\mu\) on \(\mathbb R^d\) is *locally finite* if
\(\mu(K) < \infty\) for every compact \(K \subseteq \mathbb R^d\).
#+end_quote

Equivalently, every point has a neighbourhood of finite measure. (If \(\mu\) is finite on compacts,
the closed unit ball around \(x\) is such a neighbourhood. Conversely, if every point has a finite
measure neighbourhood, cover a compact \(K\) by these neighbourhoods, extract a finite subcover, and
add up finitely many finite numbers.)

*Examples.*
- Lebesgue measure \(\lambda\): \(\lambda(K) \le \lambda(\text{a big cube}) < \infty\). Locally finite.
- Any probability measure (law of a random vector) is finite, hence locally finite.
- \(\mu = \sum_{n \ge 1} \delta_n\) on \(\mathbb R\) (a point mass at each positive integer): a compact
  set is bounded, so contains only finitely many integers. Locally finite, though \(\mu(\mathbb R)=\infty\).
- *Non-example:* \(\mu = \sum_{n\ge1}\delta_{1/n}\). The compact set \([0,1]\) contains all points
  \(1/n\), so \(\mu([0,1]) = \infty\). Not locally finite: every neighbourhood of \(0\) has infinite measure.
- *Non-example:* counting measure \(\#\) on \(\mathbb R\) (number of points; \(\infty\) for infinite sets).
  \(\#([0,1]) = \infty\).

* Approximating Borel sets

** Intuition

Open sets and compact sets are the sets we "understand" geometrically. A general Borel set may be
complicated (think of the irrationals in \([0,1]\), which contain no interval at all). Regularity
says that, *as far as the measure can tell*, every Borel set is almost compact from the inside and
almost open from the outside:

#+begin_example
        U (open, slightly bigger)
   +-------------------------------+
   |    E (arbitrary Borel set)    |
   |   +-----------------------+   |
   |   |  K (compact, slightly |   |
   |   |      smaller)         |   |
   |   +-----------------------+   |
   +-------------------------------+
          mu(U \ K) < epsilon
#+end_example

** The theorem

#+begin_quote
*Theorem 8.1 (Regularity on Euclidean space).* Let \(\mu\) be a locally finite Borel measure on
\(\mathbb R^d\). For every Borel set \(E\),
\[
\mu(E) = \sup\{\mu(K) : K \subseteq E,\ K \text{ compact}\} = \inf\{\mu(U) : E \subseteq U,\ U \text{ open}\}.
\]
The equalities are understood in \([0,\infty]\). If \(\mu(E) < \infty\), then for every
\(\varepsilon > 0\) there are such \(K\) and \(U\) with \(\mu(U \setminus K) < \varepsilon\).
#+end_quote

The first equality is called *inner regularity*, the second *outer regularity*. Neither asserts that
a *best* compact or open set exists: the sup and inf need not be attained (see Example A below).

** Proof

The proof goes in four steps: finite measure and open sets; finite measure and all Borel sets (with
closed inner sets); upgrade closed to compact; finally remove the finiteness assumption.

*Step 1. Open sets, finite \(\mu\).* Assume \(\mu(\mathbb R^d) < \infty\). Let \(U\) be open. Define
\[
K_n := \{x \in \mathbb R^d : |x| \le n,\ \operatorname{dist}(x, U^c) \ge 1/n\},
\]
where \(|x|\) is the Euclidean norm and \(\operatorname{dist}(x,A) = \inf_{y\in A}|x-y|\), with
\(\operatorname{dist}(x,\emptyset) = \infty\).

- Each \(K_n\) is closed (since \(x\mapsto |x|\) and \(x \mapsto \operatorname{dist}(x,U^c)\) are
  continuous, and we take preimages of closed sets) and bounded, hence compact.
- \(K_n \subseteq U\): a point with positive distance from \(U^c\) is not in \(U^c\).
- \(K_n\) increase with \(n\) and their union is \(U\): if \(x \in U\), openness gives a ball
  \(B(x,r) \subseteq U\), so \(\operatorname{dist}(x,U^c) \ge r\); take \(n \ge \max(|x|, 1/r)\).
  (For \(U = \mathbb R^d\) the \(K_n\) are just closed balls.)

Continuity from below gives \(\mu(K_n) \uparrow \mu(U)\); since \(\mu(U) < \infty\), this means
\(\mu(U \setminus K_n) \to 0\).

*Step 2. From open to Borel sets (closed inside, open outside).* Still with \(\mu\) finite, let
\(\mathcal G\) be the collection of Borel sets \(E\) such that for every \(\varepsilon>0\) there are
a closed \(F\) and an open \(G\) with
\[
F \subseteq E \subseteq G, \qquad \mu(G \setminus F) < \varepsilon .
\]
We show \(\mathcal G\) is a \(\sigma\)-algebra containing all open sets; then \(\mathcal G\) contains
\(\sigma(\text{open sets}) = \mathcal B(\mathbb R^d)\). This is the "good sets principle".

- /Open sets are in \(\mathcal G\)./ For open \(E\), take \(G = E\) and \(F = K_n\) from Step 1 (compact,
  hence closed).
- /Complements./ If \(F \subseteq E \subseteq G\), then \(G^c \subseteq E^c \subseteq F^c\), where
  \(G^c\) is closed and \(F^c\) is open, and \(F^c \setminus G^c = G \setminus F\). Same error.
- /Countable unions./ Let \(E = \bigcup_{j\ge1} E_j\) with \(E_j \in \mathcal G\). Choose closed
  \(F_j\) and open \(G_j\) with \(F_j \subseteq E_j \subseteq G_j\) and
  \(\mu(G_j\setminus F_j) < \varepsilon 2^{-j-2}\).
  - Outer set: \(G = \bigcup_j G_j\) is open, contains \(E\), and
    \(G \setminus E \subseteq \bigcup_j (G_j \setminus E_j)\), so
    \(\mu(G\setminus E) \le \sum_j \varepsilon 2^{-j-2} = \varepsilon/4\).
  - Inner set: an infinite union of closed sets need not be closed, so we cut off. Since
    \(\bigcup_{j \le N} E_j \uparrow E\) and \(\mu\) is finite, choose \(N\) with
    \(\mu(E \setminus \bigcup_{j=1}^N E_j) < \varepsilon/2\). The finite union
    \(F = \bigcup_{j=1}^N F_j\) is closed, lies in \(E\), and
    \[
    \mu(E\setminus F) \le \mu\Big(E \setminus \bigcup_{j=1}^N E_j\Big) + \sum_{j=1}^N \mu(E_j \setminus F_j) < \frac{\varepsilon}{2} + \frac{\varepsilon}{4} = \frac{3\varepsilon}{4}.
    \]
  - Hence \(\mu(G \setminus F) = \mu(G\setminus E) + \mu(E\setminus F) < \varepsilon\).

  (\(\mathbb R^d\) itself is open, so \(\mathcal G\) is nonempty.) Thus \(\mathcal G\) is a
  \(\sigma\)-algebra containing the open sets, so it contains every Borel set.

*Step 3. Make the inner set compact.* A closed set \(F\) need not be compact (e.g. \(F = \mathbb R\)).
But \(F \cap \{|x|\le n\}\) is closed and bounded, hence compact, and increases to \(F\). Since
\(\mu(F)<\infty\), continuity from below gives \(\mu(F \setminus (F\cap\{|x|\le n\})) \to 0\). So:
apply Step 2 with error \(\varepsilon/2\), then choose \(n\) with the extra loss below
\(\varepsilon/2\). This gives compact \(K \subseteq E \subseteq U\) open with
\(\mu(U\setminus K)<\varepsilon\), for finite \(\mu\). In particular both regularity formulas hold.

*Step 4. Localize: locally finite \(\mu\).*

- /Inner regularity./ For each \(m\), the measure \(\mu_m(A) := \mu(A \cap \{|x| \le m\})\) is finite
  (the closed ball is compact and \(\mu\) is locally finite). Apply Steps 1–3 to \(\mu_m\) and the set
  \(E \cap \{|x|\le m\}\): there are compact \(K \subseteq E\cap\{|x|\le m\}\) with \(\mu(K)\)
  arbitrarily close to \(\mu(E \cap \{|x|\le m\})\). As \(m \to \infty\), these numbers increase to
  \(\mu(E)\) by continuity from below. So \(\sup \mu(K) = \mu(E)\), even when \(\mu(E) = \infty\).
- /Outer regularity./ If \(\mu(E)=\infty\) there is nothing to prove (take \(U=\mathbb R^d\)). In general,
  split \(E\) into bounded shells \(E_m = E \cap \{m-1 \le |x| < m\}\), \(m\ge1\). Apply finite-measure
  regularity to \(\mu\) restricted to the closed ball of radius \(m+1\): get an open set containing
  \(E_m\) with excess measure \(< \varepsilon 2^{-m}\) inside that ball. Intersect it with the open
  ball of radius \(m+1\) to get an open \(U_m \supseteq E_m\) with
  \(\mu(U_m \setminus E_m) < \varepsilon 2^{-m}\). Then \(U = \bigcup_m U_m\) is open, contains
  \(E\), and \(\mu(U\setminus E) \le \sum_m \mu(U_m\setminus E_m) < \varepsilon\).
- /Both at once./ If \(\mu(E) < \infty\), take \(K\) with \(\mu(E\setminus K) < \varepsilon/2\) and
  \(U\) with \(\mu(U \setminus E) < \varepsilon/2\). Then \(\mu(U\setminus K) < \varepsilon\). \(\blacksquare\)

** Examples from the notes

#+begin_quote
*Example 8.2 (Regularity includes atoms).* For \(\mu = \delta_0\) (unit mass at the origin), the set
\(\{0\}\) is already a compact inner approximation of any Borel set containing \(0\). A Borel set not
containing \(0\) has measure zero; its outer approximation may be \(\mathbb R^d \setminus \{0\}\),
which is open and also has measure zero. Regularity does *not* say that points have measure zero.
#+end_quote

** Additional worked examples

*Example A (rationals in \([0,1]\), Lebesgue measure; the inf need not be attained).* Let
\(E = \mathbb Q\cap[0,1]\), enumerated as \(q_1, q_2, \dots\). Then \(\lambda(E) = 0\).

- /Inner:/ compact subsets of \(E\) are, e.g., finite sets of rationals; they have measure \(0\). Fine.
- /Outer:/ given \(\varepsilon\), let \(U = \bigcup_n (q_n - \varepsilon 2^{-n-1}, q_n + \varepsilon 2^{-n-1})\).
  It is open, contains \(E\), and \(\lambda(U) \le \sum_n \varepsilon 2^{-n} = \varepsilon\).
- /No minimizer:/ an open set containing \(E\) is nonempty, hence contains an interval, hence has
  positive Lebesgue measure. So \(\inf \lambda(U) = 0\) is not attained. This is exactly the remark
  "neither asserts that a minimizing open set exists".

Picture: the open set \(U\) is a dense open set of tiny total length. Open sets can be surprisingly
"thin".

*Example B (irrationals in \([0,1]\): no interval inside, but a big compact inside).* Let
\(E = [0,1]\setminus\mathbb Q\), \(\lambda(E)=1\). \(E\) contains no interval. Still, with \(U\) from
Example A, the set \(K = [0,1]\setminus U\) is closed and bounded, hence compact; it consists only of
irrationals (every rational of \([0,1]\) lies in \(U\)); and \(\lambda(K) \ge 1-\varepsilon\). So a
compact set of irrationals can have measure as close to \(1\) as we like. (Such a \(K\) is a
"fat Cantor-type set": closed, nowhere dense, yet of positive length.)

*Example C (a discrete probability law).* Let \(\mu = \sum_{n\ge1} 2^{-n}\delta_{1/n}\) on \(\mathbb R\)
(a random variable taking the value \(1/n\) with probability \(2^{-n}\)). It is finite, so
Theorem 8.1 applies. Take \(E = (0,1]\), with \(\mu(E) = 1\). The compact set
\(K_N = \{1, 1/2, \dots, 1/N\} \subseteq E\) has \(\mu(K_N) = 1 - 2^{-N} \to 1\). Is there a compact
\(K \subseteq (0,1]\) with \(\mu(K) = 1\)? It would have to contain every \(1/n\), and being closed
also their limit \(0 \notin E\). So no: again the sup is not attained.

*Example D (non-example: counting measure is not outer regular).* Let \(\#\) be counting measure on
\(\mathbb R\) (not locally finite). Take \(E=\{0\}\), so \(\#(E) = 1\). Every open \(U \ni 0\)
contains an interval, hence infinitely many points: \(\#(U)=\infty\). So
\(\inf\{\#(U): U \supseteq E \text{ open}\} = \infty \ne 1\). Local finiteness cannot be dropped.

*Example E (infinite measure).* For \(\lambda\) and \(E = [0,\infty)\), \(\lambda(E)=\infty\); the
compact sets \([0,n]\) have \(\lambda([0,n]) = n \to \infty\). Inner regularity holds with value
\(\infty\), but of course no single \(K\) and \(U\) with \(\lambda(U\setminus K)<\varepsilon\) is
claimed when \(\mu(E)=\infty\)... though here in fact \(U = (-\varepsilon/2, \infty)\) and \(K\) never
work together, since every compact \(K\) has \(\lambda(U\setminus K) = \infty\).

** Common confusions

- "Regular" is a property of the *measure*, not of the set. Every Borel set is approximable for
  every locally finite Borel measure on \(\mathbb R^d\).
- The approximating sets depend on \(\mu\). For \(\delta_0\), \(K=\{0\}\) works for \(E=[0,1]\); for
  Lebesgue measure it is useless.
- The inner sets are *compact*, the outer sets *open*; you cannot swap them (an open set inside
  \(\mathbb Q\cap[0,1]\) must be empty).

* Smooth functions between compact and open sets

** Vocabulary

A function on \(\mathbb R^d\) is *smooth* if it has continuous partial derivatives of every order.
Its *support* \(\operatorname{supp}\varphi\) is the *closure* of \(\{x : \varphi(x) \ne 0\}\). We
write \(C_c^\infty(\mathbb R^d)\) for the smooth functions with compact support ("test functions").

Example: \(\varphi(x) = x\) on \(\mathbb R\) has support \(\mathbb R\) (not compact). The function
\(\max(0, 1-|x|)\) ("tent") has support \([-1,1]\) but is not smooth (corners at \(-1,0,1\)).

** Intuition

Indicator functions \(\mathbf 1_K\) jump. We want a smooth "plateau" function that is \(1\) on
\(K\), \(0\) far away, and transitions smoothly in the gap between \(K\) and the complement of \(U\):

#+begin_example
     1 |        ___________
       |       /    K      \
       |      /             \
     0 |_____/               \______
          |<-  U  (support inside U) ->|
#+end_example

The building block is the classical bump \(e^{-1/(1-x^2)}\), which is smooth even though it is
identically zero outside \((-1,1)\).

#+begin_quote
*Lemma 8.3 (Smooth cutoff).* If \(K \subseteq U \subseteq \mathbb R^d\), with \(K\) compact and \(U\)
open, there is \(\varphi \in C_c^\infty(\mathbb R^d)\) such that \(0\le\varphi\le1\),
\(\varphi = 1\) on \(K\), and \(\operatorname{supp}\varphi \subseteq U\).
#+end_quote

** Proof

If \(K = \emptyset\), take \(\varphi = 0\). Otherwise:

*Room between \(K\) and \(U^c\).* Choose \(\delta>0\) such that the closed \(3\delta\)-neighbourhood
\(\{x : \operatorname{dist}(x,K)\le 3\delta\}\) lies in \(U\). This is possible: if \(U = \mathbb R^d\)
any \(\delta\) works; otherwise \(x\mapsto\operatorname{dist}(x,U^c)\) is continuous and positive on
the compact \(K\), so it has a positive minimum \(m\); take \(3\delta < m\).

*A mollifier.* Let \(\rho\ge0\) be smooth, supported in the closed unit ball, with
\(\int_{\mathbb R^d}\rho(x)\,dx = 1\). Concretely, normalize
\[
\rho_0(x) = \begin{cases} \exp\!\big(-1/(1-|x|^2)\big), & |x|<1,\\ 0, & |x|\ge 1.\end{cases}
\]
Why is \(\rho_0\) smooth across \(|x|=1\)? With \(t = 1-|x|^2 \downarrow 0\), each derivative inside
the ball is a finite sum of terms (bounded polynomial factor) \(\times\, t^{-m} e^{-1/t}\), and
\(t^{-m}e^{-1/t} \to 0\) as \(t\downarrow0\) for every integer \(m\ge0\) (exponential beats any power:
substitute \(u = 1/t\), then \(u^m e^{-u}\to0\)). So all derivatives extend continuously by \(0\).

Put \(\rho_\delta(x) = \delta^{-d}\rho(x/\delta)\): supported in the ball of radius \(\delta\), still
of integral \(1\) (change of variables \(x = \delta y\)).

*The cutoff.* Using Lebesgue measure, define
\[
\varphi(x) := \int_{\{y : \operatorname{dist}(y,K)\le 2\delta\}} \rho_\delta(x-y)\,dy .
\]
- \(0 \le \varphi \le \int \rho_\delta = 1\).
- If \(x\in K\): the function \(y\mapsto\rho_\delta(x-y)\) lives on the ball \(|y-x|\le\delta\), which
  lies inside the integration set (points within \(\delta\) of \(K\)). So \(\varphi(x) = 1\).
- If \(\operatorname{dist}(x,K) > 3\delta\): for \(y\) in the integration set,
  \(|x-y| \ge \operatorname{dist}(x,K) - \operatorname{dist}(y,K) > \delta\), so the integrand is
  \(0\) and \(\varphi(x) = 0\). Hence \(\operatorname{supp}\varphi\subseteq\{\operatorname{dist}(\cdot,K)\le3\delta\}\),
  which is compact and inside \(U\).

*Smoothness (differentiating under the integral).* For the partial derivative in coordinate \(i\),
look at the difference quotient \(\big(\rho_\delta(x+he_i-y) - \rho_\delta(x-y)\big)/h\). By the
mean value theorem it is bounded in absolute value by \(\sup_z|\partial_i\rho_\delta(z)| < \infty\).
A constant is integrable over the *bounded* integration set, so dominated convergence (as
\(h\to0\)) gives
\[
\partial_i\varphi(x) = \int_{\{\operatorname{dist}(y,K)\le2\delta\}} \partial_i\rho_\delta(x-y)\,dy .
\]
The same domination and continuity of \(\partial_i\rho_\delta\) show (again by dominated
convergence) that \(\partial_i\varphi\) is continuous. Repeat for all higher derivatives. \(\blacksquare\)

Note: Lebesgue measure was used *only to build* \(\varphi\). In what follows, errors are measured in
the possibly very different measure \(\mu\).

** Worked example: an explicit one-dimensional cutoff

Let \(K=[0,1]\), \(U = (-1,2)\). Let \(g(t) = e^{-1/t}\) for \(t>0\), \(g(t) = 0\) for \(t\le0\)
(smooth by the argument above). Define the smooth step
\[
S(t) = \frac{g(t)}{g(t)+g(1-t)} ,
\]
which is \(0\) for \(t\le0\), \(1\) for \(t\ge1\), smooth, with values in \([0,1]\) (the denominator
never vanishes, because \(t\) and \(1-t\) cannot both be \(\le 0\)). Then
\[
\varphi(x) = S\big(2(x+1/2)\big)\cdot S\big(2(3/2-x)\big)
\]
equals \(1\) on \([0,1]\) (both arguments \(\ge1\)), vanishes for \(x\le-1/2\) or \(x\ge3/2\), and so
\(\operatorname{supp}\varphi = [-1/2,3/2] \subseteq (-1,2)\).

** Density in \(L^p(\mu)\)

#+begin_quote
*Theorem 8.4 (Density of smooth functions).* Let \(\mu\) be a locally finite Borel measure on
\(\mathbb R^d\) and \(1\le p<\infty\). For every \(f\in L^p(\mu)\) and \(\varepsilon>0\), there is
\(\varphi\in C_c^\infty(\mathbb R^d)\) such that \(\|f-\varphi\|_{L^p(\mu)}<\varepsilon\).
#+end_quote

*Proof idea.* Indicators \(\to\) simple functions \(\to\) general functions. At each stage the
approximation error is controlled by a tool we already have: regularity, Minkowski, dominated
convergence.

*Step 1. Indicators of finite-measure sets.* Let \(E\) be Borel with \(\mu(E)<\infty\). By
Theorem 8.1 choose compact \(K\) and open \(U\) with \(K\subseteq E\subseteq U\) and
\(\mu(U\setminus K)\) small, and let \(\varphi\) be the cutoff from Lemma 8.3. On \(K\), both
\(\mathbf 1_E\) and \(\varphi\) equal \(1\); outside \(U\), both equal \(0\). In between,
\(|\mathbf 1_E-\varphi|\le1\). Therefore
\[
\|\mathbf 1_E-\varphi\|_p^p = \int|\mathbf 1_E-\varphi|^p\,d\mu \le \mu(U\setminus K),
\]
which can be made arbitrarily small.

*Step 2. Simple functions.* Let \(s\in L^p\) be simple, written via its distinct nonzero values as
\(s = \sum_{j=1}^m a_j\mathbf 1_{E_j}\), \(E_j = \{s = a_j\}\) (disjoint). Each \(E_j\) has finite
measure because \(|a_j|^p\mu(E_j)\le\int|s|^p\,d\mu<\infty\). If \(s=0\) we are done. Otherwise, for
a target error \(\eta>0\), choose by Step 1 cutoffs \(\varphi_j\) with
\(\|\mathbf 1_{E_j}-\varphi_j\|_p<\eta/(m(1+|a_j|))\). Then \(\sum_j a_j\varphi_j\in C_c^\infty\), and
Minkowski's inequality gives
\[
\Big\|s-\sum_{j=1}^m a_j\varphi_j\Big\|_p \le \sum_{j=1}^m|a_j|\,\|\mathbf 1_{E_j}-\varphi_j\|_p < \sum_{j=1}^m \frac{\eta}{m} = \eta .
\]

*Step 3. General functions.* Let \(f\ge0\) be in \(L^p\). Take the increasing simple functions
\(s_n\uparrow f\) of Lemma 6.2. Since \(0\le s_n\le f\), each \(s_n\in L^p\), and
\(|f-s_n|^p\le f^p\), which is integrable. Dominated convergence gives \(\|f-s_n\|_p\to0\). Choose
\(n\) with \(\|f-s_n\|_p<\varepsilon/2\), then by Step 2 a \(\varphi\) with
\(\|s_n-\varphi\|_p<\varepsilon/2\); the triangle inequality finishes. For signed \(f = f^+-f^-\),
approximate \(f^+\) and \(f^-\) each within \(\varepsilon/2\) and subtract. \(\blacksquare\)

*Completion.* The same holds for the completion of \(\mu\): by Proposition 5.14, each
completed-measurable set differs from a Borel set by a subset of a Borel null set, so its indicator
is the same \(L^p\) element as a Borel indicator, and the argument is unchanged.

** Examples from the notes

#+begin_quote
*Example 8.5 (Why smoothing the original representative can fail).* Take \(\mu=\delta_0\) on
\(\mathbb R\) and \(f = \mathbf 1_{\{0\}}\). Its \(L^p(\delta_0)\) norm is \(1\). Convolving \(f\) with
any smooth kernel using *Lebesgue* integration gives the zero function, because \(f=0\) Lebesgue-almost
everywhere. Thus this operation cannot approximate \(f\) in \(L^p(\delta_0)\). A smooth cutoff equal
to \(1\) at zero, on the other hand, represents exactly the same \(L^p(\delta_0)\) element as \(f\).
The cutoff construction approximates with respect to the intended measure.
#+end_quote

Explanation for beginners: in \(L^p(\delta_0)\), two functions are "the same" iff they agree at the
single point \(0\) (everything else is a null set). So \(\|g\|_{L^p(\delta_0)} = |g(0)|\). The usual
textbook trick "mollify \(f\) by convolution" is tied to Lebesgue measure, and for Lebesgue measure
\(f\) is invisible. The proof of Theorem 8.4 never convolves \(f\); it only convolves indicators of
*sets chosen using \(\mu\)*.

#+begin_quote
*Example 8.6 (Why the restriction to finite \(p\) matters).* On \(\mathbb R\) with Lebesgue measure,
let \(f = \mathbf 1_{(0,1)}\). No continuous function \(\varphi\) can have
\(\|f-\varphi\|_\infty<1/2\). Indeed, an essential error bound \(c<1/2\) implies \(\varphi\le c\)
everywhere on \((-\infty,0)\) and \(\varphi\ge1-c\) everywhere on \((0,1)\): any strict violation at
one point would persist on an interval of positive measure by continuity. Taking one-sided limits at
zero contradicts continuity. Smooth functions are therefore not dense in this \(L^\infty\) space.
#+end_quote

Spelled out: the one-sided limits give \(\varphi(0)\le c\) and \(\varphi(0)\ge1-c\), so
\(1-c\le c\), i.e. \(c\ge1/2\). Contradiction. Intuitively, the sup norm sees the jump no matter how
narrow the transition region is, whereas \(L^p\) norms with \(p<\infty\) only see the *area* of the
transition region.

** Additional worked examples

*Example F (a trapezoid approximating \(\mathbf 1_{[0,1]}\) in \(L^p(\lambda)\)).* Let \(\delta>0\) and
let \(\psi_\delta\) be \(1\) on \([0,1]\), \(0\) outside \((-\delta,1+\delta)\), linear in between.
The error \(|\mathbf 1_{[0,1]}-\psi_\delta|\) is nonzero only on the two ramps, where it equals
\(\psi_\delta\) itself, going linearly from \(0\) to \(1\) over length \(\delta\). So
\[
\|\mathbf 1_{[0,1]}-\psi_\delta\|_p^p = 2\int_0^\delta\Big(\frac{t}{\delta}\Big)^p dt = \frac{2\delta}{p+1}\xrightarrow[\delta\to0]{}0 .
\]
(\(\psi_\delta\) is continuous, not smooth; the smooth version of Lemma 8.3 behaves the same way.)
But \(\|\mathbf 1_{[0,1]}-\psi_\delta\|_\infty = 1\) for every \(\delta\) — compare Example 8.6.

*Example G (a die roll as a measure on \(\mathbb R\)).* Let \(\mu = \frac16\sum_{k=1}^6\delta_k\) be the
law of a fair die. Then \(\|g\|_{L^p(\mu)}^p = \frac16\sum_{k=1}^6|g(k)|^p\): only the values at
\(1,\dots,6\) matter. Any \(f\) is approximated *exactly* by a test function: choose bumps
\(\varphi_k\) equal to \(1\) at \(k\) with supports in \((k-1/2,k+1/2)\), and put
\(\varphi = \sum_k f(k)\varphi_k\). Then \(\varphi(k) = f(k)\) for each \(k\), so
\(\|f-\varphi\|_{L^p(\mu)} = 0\). For instance \(f = \mathbf 1_{\{\text{even}\}}\) is represented by
\(\varphi_2+\varphi_4+\varphi_6\).

*Example H (mixed measure).* Let \(\mu = \lambda|_{[0,1]} + \delta_{2}\) and
\(f = \mathbf 1_{[0,1/2]} + 5\cdot\mathbf 1_{\{2\}}\). A good approximation: a smooth function close
to \(1\) on \([0,1/2]\) with thin ramps (Example F), plus \(5\) times a bump equal to \(1\) at \(2\)
supported in \((1.5,2.5)\). The error comes only from the ramps inside \([0,1]\); the atom is matched
exactly.

** Common confusions

- "Dense in \(L^p\)" means close in the \(L^p\) norm, *not* pointwise close everywhere. The
  approximants of \(\mathbf 1_{\mathbb Q\cap[0,1]}\) in \(L^1(\lambda)\) can simply be \(0\).
- Density fails for \(p=\infty\) (Example 8.6), and also for non-locally-finite measures in general.
- The approximating \(\varphi\) depends on \(\mu\) and \(p\).

* Approximation of functions without a finite moment

** Intuition

Some random variables have no finite mean (Cauchy distribution; \(1/U\) for \(U\) uniform on
\((0,1)\)). They are not in any useful \(L^p\), so Theorem 8.4 says nothing. But we can still
approximate them in a weaker sense: *the probability of a large error tends to zero*.

#+begin_quote
*Definition (convergence in measure, informal for now).* Functions \(g_n\) approximate \(f\) *in
measure* if for every \(\varepsilon > 0\), \(\mu(\{|f-g_n|>\varepsilon\})\to0\).
#+end_quote

In probability language: \(\mathbb P(|f(X)-g_n(X)|>\varepsilon)\to0\). This will be studied
systematically in [[file:ch14-convergence.org][Chapter 14]] as "convergence in probability".

#+begin_quote
*Proposition 8.7.* Suppose \(\mu(\mathbb R^d)<\infty\), and let \(f\) be measurable and finite almost
everywhere. There are functions \(\varphi_n\in C_c^\infty(\mathbb R^d)\) such that for every
\(\varepsilon>0\),
\[
\mu(\{|f-\varphi_n|>\varepsilon\}) \longrightarrow 0 .
\]
#+end_quote

** Proof

Change \(f\) to \(0\) on the measurable null set where \(|f| = \infty\); this changes no measure of
any \(\{|f-\varphi_n|>\varepsilon\}\). Define the truncations
\[
f_n := \max\{-n,\min\{f,n\}\} ,
\]
i.e. clip \(f\) to \([-n,n]\). Since \(|f_n|\le n\) and \(\mu\) is finite, \(f_n\in L^1(\mu)\). By
Theorem 8.4 choose \(\varphi_n\in C_c^\infty\) with \(\|f_n-\varphi_n\|_1<n^{-2}\).

Where \(|f|\le n\) we have \(f = f_n\). So if \(|f-\varphi_n|>\varepsilon\), then either \(|f|>n\) or
\(|f_n-\varphi_n|>\varepsilon\). Hence
\[
\mu(\{|f-\varphi_n|>\varepsilon\}) \le \mu(\{|f|>n\}) + \frac1\varepsilon\int|f_n-\varphi_n|\,d\mu .
\]
The last term uses the pointwise inequality
\(\varepsilon\mathbf 1_{\{|f_n-\varphi_n|>\varepsilon\}}\le|f_n-\varphi_n|\), integrated (this is
Markov's inequality). It is \(<1/(\varepsilon n^2)\to0\). The sets \(\{|f|>n\}\) decrease to
\(\emptyset\) (now \(f\) is finite everywhere), and \(\mu\) is finite, so continuity from above gives
\(\mu(\{|f|>n\})\to0\). \(\blacksquare\)

** Additional worked examples

*Example I (\(1/x\) on \((0,1]\)).* Let \(\mu = \lambda|_{(0,1]}\) and \(f(x) = 1/x\) (set \(f(0)=0\)).
\(f\notin L^1\) since \(\int_0^1dx/x=\infty\), so Theorem 8.4 does not apply. But
\(\mu(\{|f|>n\}) = \lambda((0,1/n)) = 1/n\to0\), and the truncations \(f_n = \min(1/x,n)\) are bounded.
The proof produces smooth \(\varphi_n\) with
\(\mu(\{|f-\varphi_n|>\varepsilon\})\le 1/n + 1/(\varepsilon n^2)\).

*Example J (why finiteness of \(\mu\) matters).* Let \(\mu = \lambda\) on \(\mathbb R\) and \(f\equiv1\).
Any \(\varphi\in C_c^\infty\) vanishes outside a bounded set, so \(\{|f-\varphi|>1/2\}\) contains
the complement of a bounded set and has infinite Lebesgue measure. So no sequence of test functions
approximates \(f\) in measure. (Note \(f\) is finite everywhere, but \(\mu\) is infinite.)

*Example K (why "finite a.e." matters).* If \(f = \infty\) on a set \(A\) of positive measure, then
\(|f-\varphi_n| = \infty>\varepsilon\) on \(A\) for every real-valued \(\varphi_n\), so the error
probability is at least \(\mu(A) > 0\).

** Historical remark (Lusin)

Nikolai Lusin (1912) showed that a measurable function on \([0,1]\) becomes continuous when
*restricted* to a suitable closed set whose complement has arbitrarily small Lebesgue measure.
"Continuous on the retained set" is relative to that set: e.g. \(\mathbf 1_{\mathbb Q}\) restricted to
a compact set of irrationals (Example B) is identically \(0\), hence continuous there, though
\(\mathbf 1_{\mathbb Q}\) is continuous at no point of \([0,1]\). Lusin applied this to show that an
a.e. finite measurable function can be, almost everywhere, the derivative of a continuous function.

** Classroom route (from the notes)

Prove finite-measure regularity (Steps 1–3) and explain localization; construct one smooth cutoff;
use the indicator/simple-function argument for density. The Dirac example explains why the proof
must respect the measure; the jump example explains why \(p=\infty\) is excluded. Approximation in
measure is revisited with convergence of random variables.

* Worked Exercises

** Exercise 1
Let \(\mu=\delta_0+\lambda\) on \(\mathbb R\) and \(E = \{0\}\cup(\mathbb Q\cap[1,2])\). Compute
\(\mu(E)\) and give, for \(\varepsilon>0\), an explicit compact \(K\subseteq E\) and open
\(U\supseteq E\) with \(\mu(U\setminus K)<\varepsilon\).

** Solution
\(\mu(E) = \delta_0(E)+\lambda(E) = 1 + 0 = 1\). Take \(K=\{0\}\), compact, \(\mu(K)=1\). Enumerate
\(\mathbb Q\cap[1,2] = \{q_1,q_2,\dots\}\) and let
\[
U = \Big(-\tfrac\varepsilon4,\tfrac\varepsilon4\Big)\cup\bigcup_{n}\big(q_n-\varepsilon2^{-n-2},\,q_n+\varepsilon2^{-n-2}\big).
\]
\(U\) is open and contains \(E\). \(U\setminus K\) contains no atom of \(\mu\) (the only atom is \(0\in K\)),
so \(\mu(U\setminus K) = \lambda(U\setminus K)\le\varepsilon/2+\sum_n\varepsilon2^{-n-1} = \varepsilon/2 + \varepsilon/2\).
To get strict inequality use \(\varepsilon/8\) in the first interval: then the total is at most
\(\varepsilon/4+\varepsilon/2<\varepsilon\).

** Exercise 2
Show directly from Theorem 8.1 that if two finite Borel measures \(\mu,\nu\) on \(\mathbb R^d\) agree
on all compact sets, they are equal.

** Solution
For a Borel \(E\), inner regularity gives
\(\mu(E) = \sup\{\mu(K):K\subseteq E\text{ compact}\} = \sup\{\nu(K):K\subseteq E\text{ compact}\} = \nu(E)\).
(Compact sets are also a \(\pi\)-system generating \(\mathcal B(\mathbb R^d)\), so Chapter 4's
uniqueness theorem gives another proof.)

** Exercise 3
Let \(\mu\) be locally finite on \(\mathbb R^d\) and suppose \(\int\varphi\,d\mu = 0\) for every
\(\varphi\in C_c^\infty(\mathbb R^d)\) with \(\varphi\ge0\). Show \(\mu = 0\).

** Solution
Let \(K\) be compact and \(U\supseteq K\) open with \(\mu(U)<\infty\) (e.g. \(U\) = a bounded open
neighbourhood; its closure is compact, so \(\mu(U)<\infty\)). Lemma 8.3 gives \(\varphi\) with
\(\mathbf 1_K\le\varphi\), so \(\mu(K)\le\int\varphi\,d\mu=0\). By inner regularity
\(\mu(E) = \sup_K\mu(K) = 0\) for every Borel \(E\).

** Exercise 4
Let \(\mu=\frac12(\delta_0+\delta_1)\) on \(\mathbb R\) (a fair coin with outcomes \(0,1\)). Is
\(C_c^\infty\) dense in \(L^\infty(\mu)\)? Compare with Example 8.6.

** Solution
Yes. \(\|g\|_{L^\infty(\mu)} = \max(|g(0)|,|g(1)|)\), since the only non-null sets contain \(0\) or
\(1\). Given \(f\), let \(\varphi = f(0)\varphi_0+f(1)\varphi_1\) with bumps \(\varphi_0(0)=1\),
\(\varphi_1(1)=1\), supports in \((-1/2,1/2)\) and \((1/2,3/2)\). Then \(\varphi = f\) \(\mu\)-a.e.
and the error is \(0\). Example 8.6 used Lebesgue measure, for which a jump is seen on intervals of
positive measure on both sides. So the failure for \(p=\infty\) is not universal; it is a statement
about specific measures. Theorem 8.4 just does not *guarantee* \(p=\infty\).

** Exercise 5
Let \(f\in L^1(\lambda)\) on \(\mathbb R\). Using Theorem 8.4, show that
\(\int|f(x+h)-f(x)|\,dx\to0\) as \(h\to0\) (continuity of translation).

** Solution
Given \(\varepsilon\), choose \(\varphi\in C_c^\infty\) with \(\|f-\varphi\|_1<\varepsilon/3\).
Translation invariance of \(\lambda\) gives \(\|f(\cdot+h)-\varphi(\cdot+h)\|_1<\varepsilon/3\). Since
\(\varphi\) is uniformly continuous and supported in some \([-R,R]\), for \(|h|\le1\) the function
\(\varphi(\cdot+h)-\varphi\) is supported in \([-R-1,R+1]\) and tends to \(0\) uniformly, so
\(\|\varphi(\cdot+h)-\varphi\|_1\le(2R+2)\sup|\varphi(\cdot+h)-\varphi|<\varepsilon/3\) for small \(h\).
Triangle inequality: \(\|f(\cdot+h)-f\|_1<\varepsilon\).

** Exercise 6
Let \(\mu\) be the standard Cauchy law on \(\mathbb R\) (density \(1/(\pi(1+x^2))\)) and \(f(x)=x\).
Show \(f\notin L^1(\mu)\), and compute \(\mu(\{|f|>n\})\). What does Proposition 8.7 give?

** Solution
\(\int|x|\,\frac{dx}{\pi(1+x^2)} = \frac2\pi\int_0^\infty\frac{x}{1+x^2}dx = \frac1\pi[\log(1+x^2)]_0^\infty = \infty\).
\(\mu(\{|x|>n\}) = 2\int_n^\infty\frac{dx}{\pi(1+x^2)} = \frac2\pi\big(\frac\pi2-\arctan n\big)\to0\).
Proposition 8.7 gives test functions \(\varphi_n\) with
\(\mu(\{|x-\varphi_n(x)|>\varepsilon\})\to0\): a Cauchy random variable \(X\) is, with high
probability, within \(\varepsilon\) of \(\varphi_n(X)\), even though \(\mathbb E|X| = \infty\).

*Key takeaways*

- Regularity: compact inside, open outside; the optimal sets need not exist.
- The proof pattern "good sets form a \(\sigma\)-algebra containing the open sets" appears again.
- Density of \(C_c^\infty\) in \(L^p(\mu)\) goes indicators \(\to\) simple \(\to\) general.
- \(p=\infty\) and infinite or non-locally-finite measures are genuine exceptions.
- Approximation in measure only needs \(f\) finite a.e. and \(\mu\) finite.
